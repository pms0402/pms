# VOIDRUN

한국어 UI의 브라우저용 3D 서바이벌 로그라이크입니다. Three.js로 맵, 캐릭터, 몬스터, 검격과 파티클을 직접 렌더링합니다. 별도 서버·API 키·외부 이미지 서비스가 필요하지 않으며 글꼴도 앱에 포함됩니다.

## 공개 주소와 자동 업데이트

GitHub Pages가 활성화되고 배포가 완료되면 게임 주소는 **https://pms0402.github.io/pms/** 입니다.

최초 한 번 [저장소 Settings → Pages](https://github.com/pms0402/pms/settings/pages)에서 **Build and deployment → Source → GitHub Actions**를 선택합니다. Pages를 사용할 수 없는 비공개 저장소/요금제인 경우 GitHub에서 사용 가능 여부를 먼저 확인하세요. 공개 여부는 이 설정에서 임의로 변경하지 않습니다.

그다음부터는 `main`에 업데이트를 푸시할 때마다 `.github/workflows/deploy-pages.yml`이 규칙 테스트와 빌드를 수행하고 같은 주소로 자동 배포합니다. [Actions의 Deploy VOIDRUN](https://github.com/pms0402/pms/actions/workflows/deploy-pages.yml)에서 상태를 확인하고 **Run workflow**로 다시 배포할 수도 있습니다. 배포 실패 시 기존 사이트는 유지됩니다. 채팅에서 파일을 수정한 것만으로 배포되지는 않으며, `main`으로 커밋·푸시해야 반영됩니다.

빌드 결과는 루트와 `/pms/` 하위 경로를 모두 지원합니다. `npm run build` 후 `npm run test:deploy`로 두 경로의 실제 3D 렌더링과 자산 로딩을 검사할 수 있습니다. 배포된 커밋은 사이트의 `version.json`에서 확인할 수 있습니다.

## 실행

Node.js 24 (`.nvmrc`)와 npm을 사용합니다.

```sh
npm ci --cache /tmp/voidrun-npm-cache
npm run dev -- --port 5173
```

```sh
npm test       # 경제 배율, 스폰 곡선, 경험치, 강화 규칙 6개 테스트
npm run build # dist/에 배포용 정적 파일 생성
npm run preview
```

개발 서버가 실행 중이고 Chromium이 설치되어 있으면 `npm run test:browser`로 데스크톱·모바일 조작, 일시정지, 설정 유지, 사망·재시작과 기록 저장을 검증할 수 있습니다. 기본 Chromium 경로는 `/usr/bin/chromium`이며 `CHROMIUM_PATH`로 변경합니다. 배포용 서버는 `BASE_URL=http://127.0.0.1:4173 npm run test:browser`로 검사합니다.

## 플레이

- WASD / 방향키: 화면 기준 이동
- Space: 3초 쿨다운의 무적 대시
- Escape: 일시정지 / 계속
- 공격: 자동 검격 + 가까운 적을 향한 마법 투사체
- 레벨업: 카드 클릭 또는 숫자 1–3으로 강화 선택
- 모바일: 화면 방향 버튼 또는 전장 드래그로 이동, 번개 버튼으로 대시

45초짜리 스테이지 5개를 돌파하면 승리합니다. 초반에는 적이 드물게 등장하며 시간과 스테이지에 따라 출현 간격이 줄고, 후반에는 한 번에 여러 적이 등장합니다. 최대 동시 적 수는 성능을 위해 140으로 제한합니다.

| 스테이지 | 기본 처치 골드 | 몬스터 체력 | 기본 접촉 피해 |
| --- | ---: | ---: | ---: |
| 1 | 1 | 10 | 5 |
| 2 | 10 | 32 | 16 |
| 3 | 100 | 102.4 | 51.2 |
| 4 | 1,000 | 327.68 | 163.84 |
| 5 | 10,000 | 1,048.576 | 524.288 |

몬스터 종류에 따라 체력과 보상이 추가 보정됩니다. 스테이지 돌파 시 플레이어 공격력은 2.1배, 최대 체력은 2배가 되고 체력이 전부 회복됩니다. 강화 조합으로 피해량·공격 속도·투사체·방어·재생·획득 범위를 개선할 수 있습니다. 골드는 이번 런의 획득 기록이며, 현재 버전에는 골드 상점이나 영구 성장 요소가 없습니다.

효과음·그래픽 설정과 최근 30개 런 기록은 현재 브라우저의 localStorage에 보관됩니다. 브라우저 데이터를 삭제하면 초기화됩니다. 사운드는 기본으로 꺼져 있으며 오른쪽 위 스피커 버튼으로 켤 수 있습니다. WebGL 2와 하드웨어 가속을 지원하는 브라우저가 필요합니다.

## 구성

- `src/game.js`: 3D 렌더링, 조작, 전투와 스테이지 진행
- `src/balance.js`: 경제·몬스터·출현·강화 규칙
- `src/main.js`: HUD, 가이드, 설정, 레벨업과 런 기록
- `src/style.css`: 반응형 UI

아트는 모두 절차적으로 생성한 독자적인 로우폴리 그래픽입니다. 빌드는 정적 호스팅에 배포할 수 있습니다.
