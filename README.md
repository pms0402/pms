# VOIDRUN

한국어 UI의 브라우저용 3D 서바이벌 로그라이크입니다. Three.js로 맵, 캐릭터, 몬스터, 검격과 파티클을 직접 렌더링합니다. 별도 서버·API 키·외부 이미지 서비스가 필요하지 않으며 글꼴도 앱에 포함됩니다.

## v0.16.0 — 몬스터 관절 모션·이어지는 검격·한글 키보드 패링

- 고블린·거대 괴물·수호자는 팔과 다리를 교대로 움직이며 걷습니다. 늑대·멧돼지는 네 다리, 자폭 곤충은 여섯 다리로 움직이고 슬라임은 탄성 있는 움직임을 유지합니다. 머리와 꼬리에도 작은 움직임을 더했습니다.
- 실제 근접 공격에는 팔 휘두르기, 마법사·주술사·해골 사수의 준비/발사에는 팔과 무기 동작, 돌진 준비에는 몸을 낮추는 동작을 연결했습니다. 빙결·패링 경직·일시정지는 관절 모션도 멈춥니다. 기존 접촉 피해와 공격 예고 시간은 그대로입니다.
- 플레이어는 검을 좌우로 준비→베기→회수하며 어깨·팔꿈치·손목·몸통이 함께 움직입니다. 가속과 감속을 부드럽게 이어 주며, 실제 검날 위치를 따라 짧은 리본 잔상이 남습니다. 쌍검과 반격도 각각 지원합니다. 지면 검기는 기존 사거리/부채꼴 안에서 진행 방향을 따라 그려집니다.
- 공격 속도가 높아도 모션을 매 적중마다 처음으로 돌리지 않습니다. 시각 동작만 묶어서 끝까지 보여 주며 **공격 횟수·피해·사거리·쿨다운·빌드 효과는 유지**합니다. 새로운 이펙트와 동작은 추가 피해를 만들지 않습니다.
- **F / G 패링은 한/영 상태와 Caps Lock에 관계없이 물리 키로 동작**합니다. 한글 `ㅍ`이나 IME의 `Process` 입력도 처리합니다. WASD·E·R·B·Shift+F에도 같은 처리를 적용했으며, 글 입력창과 Ctrl/Command/Alt 조합에서는 전투 단축키가 발동하지 않습니다. 키 반복으로 패링을 재시도하지 않고 키 해제·창 전환 때 이동 입력을 정리합니다. 모바일 패링 버튼은 그대로입니다.

`monster-motion.js`는 원본 메시의 부위별 회전과 그림자를 GPU 인스턴싱에 연결합니다. 기존 폴리곤·재질·텍스처를 유지하고, 군중의 개체마다 관절 메시나 드로 콜을 추가하지 않습니다. 독립 보스와 투명 부분은 같은 변형의 CPU 경로를 사용합니다. `sword-trail.js`는 최대 18개 위치/손과 고정 버퍼 하나를 재사용하며 0.14초 후 잔상이 사라집니다. 재시작·성역/비밀 공간 이동 때 잔상과 임시 변형을 정리합니다. 저장 형식과 영구 강화는 바꾸지 않습니다.

```sh
npm test
npm run build
npm run test:animation  # 관절·실제 공격·검날 잔상·160마리 GPU/CPU 시각 비교
npm run test:motion    # 30/60/120Hz·이동/정지·쌍검·풀 재사용
npm run test:parry     # 한글 IME 포함 키 입력·실제 피해 차단·경직·반격
npm run test:quality   # 원본 기하/재질·인스턴싱·자원 상한
```

브라우저 검증은 Chromium WebGL에서 수행하며 실제 모바일 Safari의 장시간 프레임은 별도 기기 검증 대상입니다. 테스트의 `BASE_URL`로 실행 중인 미리보기 서버 주소를 지정할 수 있습니다.

## v0.15.0 — 포위를 뒤집는 패링과 광역 반격

**F / G / 모바일 패링 버튼**으로 사용합니다. F를 패링으로 옮기고 전체화면은 **Shift+F 또는 기존 전체화면 버튼**으로 유지합니다. 이동·대시·자동 검격·마법·장비·직업·유물·세트·보스·변이·심연과 기존 저장 데이터는 유지합니다.

| 상태 | 판정과 보상 |
| --- | --- |
| 방어 시도 | 전방 120°, 0.45초, 재사용 4초. 즉시 검을 들어 올리며 청색 방어 궤적 표시 |
| 완벽한 패링 | 처음 0.16초 안에 막을 수 있는 전방 공격이 도착하면 피해 무효. 충돌 섬광·금속 불꽃·4m 충격파·짧은 `PERFECT PARRY` 표시 |
| 늦은 방어 | 남은 방어 시간에는 피해 65% 감소. 완벽한 패링 보상·히트 스톱·반격 충전은 지급하지 않음 |
| 실패 | 방어 만료·후방·방어 불가 공격은 정상 피해. 추가 피해나 자원 소모 없음 |
| 히트 스톱 | 성공 후 실제 시간 약 0.1초 동안 시뮬레이션만 정지. 이펙트와 렌더링은 계속되며 프레임을 차단하거나 정지분을 몰아서 재생하지 않음 |
| 광역 반격 | 성공 후 전투 시간 2초 안 첫 적중 검격에 자동 적용. 전방 180°, 기존 검 피해의 250%, 보스 ×1.2 추가. 한 번에 최대 24명 |

반격 사거리는 현재 검 범위 ×1.25, 최소 3.4m·최대 7m입니다. 기본 검은 3.5m이며 검 범위 강화·진화와 연동합니다. 검 기본 계수·선택한 진화·장비·유물·직업의 검 보너스를 기존 순서로 적용하고 **반격 ×2.5를 한 번만** 곱합니다. 기존 대시 후 첫 검격 보너스도 한 번만 소비합니다. 적이 없으면 반격 충전을 소비하지 않습니다. 빠른 연속 공격도 한 번의 충전만 사용하므로 공격 속도로 추가 반격을 만들 수 없습니다.

별도 키를 누르지 않아도 자동 검격이 반격을 발동합니다. 충전 중 F/G 또는 패링 버튼으로 즉시 공격을 시도하는 기존 방식도 지원합니다. 반격은 강한 반원형 검기와 별도 0.38초 동작·효과음으로 구분합니다. 후속 일반 공격의 피해 판정은 계속 유지합니다. 기존 검 조합과 장비 효과는 각자의 재발동 제한을 유지하며 반격 자체를 다시 충전하지 않습니다.

### 충격파와 보스 경직

성공 충격파는 표시와 동일한 **반경 4m** 안의 살아 있는 일반 적에게 적용됩니다. 공격 준비·조준·돌진 준비·폭발 준비 등을 취소하고 잠깐 밀어내 탈출 공간을 만듭니다. 직접 피해는 없으며 기존 패링 충격파 유물의 피해는 별도입니다.

- 일반 적은 0.32초 경직, 정예/복합 변이는 0.14초와 넉백 60% 저항. 강철 변이는 밀림이 추가로 35% 감소합니다.
- 같은 대상의 패링 제어는 1.5초 동안 다시 적용되지 않습니다. 반격의 일반 적 경직은 0.18초·정예 0.08초이며 이 저항을 공유합니다.
- 밀림은 짧은 구간으로 나누어 기존 벽·기둥·맵 경계 충돌을 매번 적용합니다. 개체 수 160 상한을 유지합니다.
- 공격한 보스는 기본 0.6초, 3페이즈 0.45초 경직. **5초간 경직 저항**으로 반복 잠금을 막습니다. 저항 중에도 공격 방어와 반격 충전은 가능합니다.
- 보스의 현재 돌진/검격·예약 탄막·방어 가능한 발사체는 취소하지만, 이미 생성된 방어 불가 위험 지대는 유지합니다. 경직 뒤 남은 페이즈와 주요 패턴은 재개합니다.

**청색 직선·검격 예고와 일반 탄환은 패링 가능**, 붉은 지면 원·독·용암·고리 충격파·사후 폭발·자폭의 실제 폭발은 방어 불가입니다. 충격파로 자폭 *준비*를 끊는 것과 폭발 피해를 패링하는 것은 구분합니다. 보스 체력 바 바로 아래의 작은 표시에서 경직 잔여 시간을 확인합니다. 버튼에는 재사용 시간과 반격 가능 시간이 표시됩니다.

### 타격감과 접근성

Three.js의 재사용 메시 4개·광원 1개와 기존 최대 256개 인스턴스 파티클을 사용합니다. 외부 이미지·API·오디오 파일은 추가하지 않습니다. 짧은 검 움직임 소리, 방어 충돌음, 금속 배음이 있는 완벽한 패링 소리, 반격 검기 소리는 기존 음소거 설정을 따릅니다. 섬광은 캐릭터 근처에만 표시하며 전체 화면을 번쩍이지 않습니다.

**설정 → 카메라 흔들림**에서 끄기/약하게/기본, **패링 섬광·강한 효과**에서 끄기/줄이기/기본을 선택하고 같은 브라우저에 저장합니다. 효과를 꺼도 판정 범위와 성공 안내는 유지합니다. 시스템의 `prefers-reduced-motion`이 켜져 있으면 최초 기본값은 흔들림 끄기·강한 효과 줄이기입니다. 사용자가 저장한 선택을 우선합니다. 기존 설정에 새 항목이 없어도 기본값으로 동작하며 영구 강화·지갑·이야기·런 기록을 초기화하지 않습니다.

야영지 훈련장에서도 새 방어 자세와 성공/반격 이펙트를 연습할 수 있습니다. 실제 체력·런 통계·직업/세트 보상은 연습으로 올리지 않습니다.

### 전투 통계와 검증

런 분석에 패링 시도·성공·성공률, 패링/부분 방어로 차단한 피해, 반격의 실제 피해, 보스 경직 횟수를 추가합니다. 차단 피해는 방어력을 적용한 공격을 기준으로 당시 남은 체력까지만 집계하며, 보호막 흡수 전 값입니다. 반격은 `damage.counter`에 한 번만 기록하고 초과 피해를 별도로 분리합니다. 과거 분석에 새 필드가 없으면 0으로 표시합니다.

`src/parry.js`가 판정·충전·제어·보스 취소를, `src/parry-feedback.js`가 재사용 연출을 관리합니다. 시뮬레이션·피격·검격은 `game.js`, 보스/탄환은 `bosses.js`·`boss-phases.js`·`hidden-bosses.js`, 동작은 `creatures.js`, UI/저장은 `main.js`·`expansion-ui.js`·`chronicle-ui.js`·`analytics.js`에서 연결합니다. 탄환 순회 중 패링 유물이 보스를 처치해도 제거된 탄환을 다시 참조하지 않도록 정리 경로를 보호했습니다.

```sh
npm test
npm run build
npm run preview -- --port 5174
BASE_URL=http://127.0.0.1:5174 npm run test:parry
```

신규 자동 검사는 실제 WebGL에서 성공·실패·부분 방어, F/G와 Shift+F, 정확한 광역 반격 피해/범위/대상 제한과 보너스 중복 방지, 6종 일반 보스와 히든 왕의 공격 취소·경직·3페이즈 복귀, 방어 불가 지대 보존, 벽/경계 밀림, 히트 스톱·일시정지·재시작, 유물로 보스를 처치하는 탄환 순회, 160마리 상황, 접근성 저장과 모바일 조작을 확인합니다. 실기기 iPad Safari의 장시간 프레임과 체감 타이밍·후반 난이도는 별도 플레이 조정 대상입니다.

최종 로컬 검증: **단위 테스트 169/169**, 기존 21종과 신규 `parry`를 합한 **브라우저 스위트 22종 통과**, 프로덕션·단독 HTML 빌드 통과. 신규 검사는 160마리와 반복 패링에서 임시 연출을 실제 렌더링하고, 기하 122개·텍스처 15개·재사용 연출 자식 5개 및 재시작 정리를 확인했습니다. 루트와 `/pms/`의 정적 자산 로딩, 격리 iframe, 기존 장비·직업·세트·유물·보스/히든 보스·저장·기본 모션·그래픽 품질 회귀 검사도 통과했습니다.

## v0.14.0 — 야영지, 비밀의 세계와 전투 기록

일반 1–10층, 무한 심연, 지역·경로 분기, 기존 캐릭터·무기·조합·유물·NPC·패링·영구 강화와 정산을 유지합니다. 층 이동만으로 플레이어 능력치를 올리거나 회복시키지 않습니다.

### 신규 직업 4종

시작 화면의 캐릭터·무기 또는 **3D 야영지 → 훈련장**에서 영구 골드로 해금하고 선택합니다. 기존 비전술사 150G·광전사 200G보다 높은 250–350G로 설정하고, 강점에 대응하는 체력·속도·검 피해 약점을 둡니다. 시작 무기 3종은 그대로 조합할 수 있습니다.

| 직업 | 해금 | 시작 능력과 실제 패시브 |
| --- | --- | --- |
| 암살자 | 250G | 속도 +15%, 체력 -15%, 치명타 +6%p. 대시 후 3초 안 첫 검격 +20%, 처치 후 1.5초 이동 +15% |
| 소환술사 | 300G | 마법 +18%, 검 -25%. 소환수 1마리가 12m 안 가장 가까운 적을 1.2초 간격으로 공격. 직접 마법 8회 적중 시 다음 소환수 공격 ×1.8; 같은 적 충전은 0.2초 간격 |

기존 곡면 캐릭터에 직업 색상과 어깨 칼날·후광·방패·뿔을 적용합니다. 전투 중 작은 상태 표시에서 중첩·보호막·재사용 시간을 확인하고, 선택 화면에서 전체 조건을 읽을 수 있습니다. 소환수·장비·세트 추가 공격은 직접 마법 충전이나 세트/장비 연쇄를 다시 발생시키지 않습니다.

### 자유 이동 3D 야영지

시작 화면이나 런 결과의 **3D 야영지** 버튼으로 진입합니다. **WASD / 방향키 / 모바일 방향 버튼·드래그**로 이동하고, 시설 근처에서 **R / 시설 이용**을 누릅니다. 하단 빠른 메뉴로 시설 앞에 이동해 바로 열 수도 있습니다. 시설 화면이 열려 있으면 야영지 이동을 멈춥니다. 전투 시간·몬스터 AI·런 통계는 진행하지 않습니다.

- **대장간:** 기존 시작 무기 선택·해금, 장비와 세트 정보.
- **훈련장:** 직업 선택·해금, 조작 가이드, 실제 전방/타이밍 판정으로 안전한 패링·반격 연습. 연습은 체력을 깎거나 런 통계를 올리지 않습니다.
- **마법 연구소:** 모든 마법·진화와 숨겨진 조합 7종의 조건 및 효과.
- **기록관:** 몬스터/지역/변이 도감, 이야기·히든 보스 조건·엔딩, 최근 런 분석.
- **강화 제단:** 기존 가지형 영구 강화 트리와 지갑. 구매·직업 선택은 다음 런에 실제 반영됩니다.
- **탐험의 문:** 일반/심연 선택, 위험 계약, 새 런 시작. 심연 해금 조건은 기존 일반 10층 승리입니다.

야영지는 별도 `camp` 상태이며 기존 재질·NPC 모델을 재사용합니다. 전체화면 버튼(현재 Shift+F), 기존 단축 메뉴와 직접 런 시작도 유지합니다.

### 비밀 방과 숨겨진 던전

짝수 층 진행 40초 이후 또는 정예 처치 뒤 **실제 3D 균열**이 나타납니다. 공허 지역에도 입구가 생깁니다. 근처에서 **R / 비밀 입구**로 선택하고, 방 안 **위쪽 제단(0, -3)**에서 기록·보상을 확인합니다. **아래쪽 황금 복귀 문(0, 10)**에서는 보상 없이도 언제든 원래 전장으로 돌아갈 수 있습니다. 입구는 층당 한 번 이용합니다.

| 공간 | 내용과 선택 |
| --- | --- |
| 고대의 방 | 전투 없이 왕의 맹세 기록 발견. 기본 2층 입구에서 만날 수 있음 |
| 보물의 방 | 희귀 이상 장비 3개 중 하나, 기본 처치 골드 20배 |
| 시련의 방 | 정예 4마리, 정예 기본 체력·피해에서 추가 ×1.2. 완료 시 영웅 이상 장비 선택·기본 처치 골드 35배 |
| 저주의 방 | 포기 가능. 수락하면 추가 체력·피해 ×1.3 정예 3마리와 전투하고 영웅 이상 보상 |
| 매몰된 비밀 던전 | 왕의 맹세 발견 후 입구의 추가 선택 또는 공허 입구. 추가 체력·피해 ×1.35 정예 6마리와 별도 미니보스, 매몰된 진실 기록·매몰된 유산 장비 |

골드는 기존 지역·계약·유물 배율을 적용합니다. 별도 전투 공간은 경계와 기둥 충돌을 적용하고 위험 지형 대신 고유 조명을 사용합니다. 입장 전에 적과 탄환의 합산 상한을 확보하며, 주변 적·탄막이 너무 많으면 입구를 소비하지 않고 정리 후 입장하도록 안내합니다.

진입 때 원래 적·보스 객체와 체력, AI 타이머, 탄환, 장판, 마법·변이 시스템, 상자, 미수집 장비, 위치와 층 시간을 보관합니다. 방의 전투 시간은 전체 런 시간에 포함하지만 **원래 층 시간과 NPC 생존 계약 시간은 정지**합니다. 복귀는 같은 객체와 시스템을 복원하고 별도 방의 적·탄환·장판·미수집 물품을 정리합니다. 얻은 장비·골드·경험치·선택한 강화는 유지하며 체력을 자동 회복하지 않습니다. 일반 층 보스 출현·진행·유산 보상은 비밀 공간에서 중복 실행하지 않습니다.

### 장비 세트 5종

기존 4부위의 **현재 장착품만** 계산합니다. 교체·버리기·재설정 때 다시 계산하고, 이전 장비에 `setId`가 없어도 그대로 사용할 수 있습니다. 전체 장비의 45%가 세트 장비입니다. 지역 선호 세트는 29%, 나머지 세트는 각각 4%로 모든 지역에서 획득 가능하며, 성역처럼 선호가 없는 곳은 각각 9%입니다. 세트 색 오라와 **E 장비 / 세트 도감**에서 2개·4개 조건을 확인합니다.

| 세트 · 선호 지역 | 2개 | 4개 |
| --- | --- | --- |
| 화염 군주 · 화산 | 화염 피해 +15% | 직접 화염 적중 시 15% 추가 폭발, 마법 피해 30%, 주변 최대 5명, 3초 간격 |
| 빙결 수호자 · 설원 | 서리 피해 +15%, 둔화 +5%p·지속 +10% | 둔화 적 직접 타격 시 주변 최대 4명에게 마법 피해 25%, 2.5초 간격. 추가 빙결·넉백 없음 |
| 공허 추적자 · 공허 | 치명타 +5%p | 대시 후 2.5초 검 속도 +20% |
| 심연 기사 · 숲 | 최대 체력 +12%, 피해 감소 +3%p | 완벽한 패링 후 최대 체력 12% 보호막, 5초 지속·8초 간격 |

기본 장비·유물 배율에 세트 피해를 곱합니다. 치명타 65%, 피해 감소 60%, 검 속도 초당 30회 등 기존 상한을 유지합니다. 추가 피해는 다른 세트·장비·숨겨진 조합을 다시 발동하지 않습니다. 최대 체력 세트 착용은 현재 체력을 회복하지 않습니다. 성기사 보호막과 심연 기사 보호막은 남은 양만 순서대로 흡수하고 무한 회복하지 않습니다.

### 히든 보스와 세계의 기록

기록관에 조건과 공략을 표시합니다. 조건을 실제 달성한 뒤 전장의 균열에서 **선택형 전용 공간**으로 진입합니다. 직업이나 세트는 해금 조건이 아닙니다. 모든 보스는 실제 모델과 고유 패턴, 기존의 작은 상단 체력 바와 70%/35% 페이즈를 사용합니다. 페이즈 전환은 이전 예고·예약 공격을 취소하고 다시 준비합니다.

| 보스 | 해금 조건 | 전투와 고유 보상 |
| --- | --- | --- |
| 잊혀진 왕 | 고대의 방 왕의 맹세 + 일반 2층 보스 처치 | 중갑과 거대한 검. 전방 120° 검격은 1.1초/최종 0.85초 예고 후 정면 패링 가능, 후반 부채꼴 탄막. 왕의 유산: 영웅 이상 심연 기사 세트 |
| 공허의 관측자 | 공허 지역 NPC 이벤트를 포기하지 않고 완료 + 비밀 던전 클리어 | 거대한 눈과 공전 조각. 도착 예고 후 순간이동·5/7/9방향 탄막·후반 공간 균열. 관측자의 유산: 영웅 이상 공허 추적자 세트 |
| 태초의 심연 | 심연 25층 도달 + 왕·관측자 처치 기록 | 촉수와 핵. 지면 파동과 손아귀·후반 연계 탄막. 최종 페이즈는 1.35초 예고 뒤 반경 4–12m 고리 공격, 중앙 4m가 안전. 태초의 유산: 전설 폭풍 현자 세트 |

왕·관측자 체력은 해당 층 기본 보스의 ×1.2, 태초는 ×1.6이며 기존 난이도 배율을 적용합니다. 완료 제단의 추가 골드는 기본 처치 골드 35배입니다. 실제 처치가 영구 기록과 이야기 조건을 갱신하며, 일반 층의 보스 완료 판정은 바꾸지 않습니다.

주요 기록 6개와 지역·히든 보스 기록을 포함해 **13개 기록**을 발견할 수 있습니다. 긴 강제 연출 대신 발견 알림과 기록관의 다시 읽기를 제공합니다. 엔딩은 런을 마친 뒤 결과 화면·메뉴·야영지에서 **조건과 실제 선택**을 함께 충족해야 저장되며, 다시 보거나 건너뛰고 다음 탐험을 계속할 수 있습니다.

| 결말 | 달성 조건과 선택 |
| --- | --- |
| 성역의 수호자 | 일반 10층 클리어 → 성역을 복구한다 |
| 공허의 계승자 | 관측자의 렌즈·매몰된 진실 + 관측자 처치 → 공허의 힘을 받아들인다 |
| 끝없는 순환 | 심연 20층의 순환 기록 + 심연 30층 도달 → 다음 순환으로 향한다 |
| 최초의 균열 | 주요 기록 6개 + 히든 보스 3종 처치 → 균열의 진실을 세상에 전한다 |

### 전투 통계와 빌드 분석

런 결과와 **런 기록 / 야영지 기록관**에서 확인합니다. 기존 최근 30런 저장 구조에 선택적 `analytics`를 추가하고, 과거 기록의 시간·처치·골드는 유지합니다. 직업·일반/심연 필터, 최고 층/처치/골드, 직업별 기록·평균 실제 DPS를 비교할 수 있습니다. 성장 단계와 도달 층이 다른 기록이므로 직업 순위로 단정하지 않습니다.

- 실제 플레이 시간·층, 일반/정예/보스 처치, 실제 받은 피해·회복량, 대시·완벽한 패링 성공/시도, 총 획득/사용 후 회수 골드와 장비 수집 수.
- **검·화염구·서리·번개·궤도·숨겨진 조합·장비·반격·소환수·세트·유물·기타**를 한 번씩만 집계. 남은 적 체력까지만 피해로 기록하고 초과 피해는 별도 표시합니다.
- 피해 비중 막대, 시간별 DPS 선 그래프, 층별 처치/받은 피해 막대와 최종 직업·무기·능력치·마법·진화·유물·장착품 요약.
- 긴 심연에서도 DPS 최대 180구간(자동 합산), 최근 200층 상세 행, 최근 32개 획득 장비 이름과 전체 획득 수를 보관해 저장·계산량을 제한합니다.

`voidrun.progression`의 기존 강화·해금·골드·정산 영수증을 보존합니다. `voidrun.story`에 발견·히든 보스 처치·선택한 엔딩을 추가하고, 기존 일반 승리/심연 최고 기록에서 확인 가능한 진행을 이전합니다. 명시적인 저장 초기화는 이야기와 분석 기록도 지우고 설정·다른 앱 데이터는 유지합니다.

### 보스의 세 전투 페이즈

모든 보스는 체력 **70% 미만에 2페이즈, 35% 미만에 3페이즈**로 바뀝니다. 큰 피해로 두 구간을 넘으면 각 전환을 한 번씩 기록합니다. 전환은 체력을 회복하지 않으며 이전 예고·예약 공격을 정리하고 잠시 준비 시간을 둡니다. 오라와 상단 보스 바에서 페이즈를 확인할 수 있습니다.

| 유형 | 추가 특수 패턴 |
| --- | --- |
| 돌진 수호자 | 예고를 갱신하는 연속 돌진 2회, 최종 페이즈 3회 후 충격파 |
| 포격 사냥꾼 | 1.1초 조준 후 1초만 완만히 추적하는 탄환, 지연 폭격 |
| 역병 지배자 | 중앙에 공간을 남기는 독의 고리, 최종 페이즈 지속 시간 증가 |
| 군단 소환자 | 체력 ×1.25 하위 병력과 좌우 진형 충격. 소환 총량·동시 적 상한 유지 |
| 폭풍 군주 | 빈틈 있는 회전 탄막과 지연 낙뢰 |
| 순간이동 망령 | 좌우 잔상 파동, 강화형/최종 페이즈의 세 번째 지연 잔상 |

7–10층 강화 보스의 기존 추가 패턴도 유지합니다. 새 특수 패턴은 기본 패턴이 준비 중이고 기존 예약 공격이 없을 때 시작하며, 최종 페이즈에서는 특수 패턴 주기가 11초에서 8초로 줄어듭니다. 지면 원형 위험의 붉은 경계는 방어 불가를 뜻합니다. 예고 중 이동·대시로 벗어날 수 있고 대화·일시정지에서는 시간이 멈춥니다.

### 장비 파밍과 관리

무기·방어구·반지·목걸이 **4부위**, 부위마다 1개 장착. 가방은 장착품을 포함해 **16개**, 미수집 드롭은 **12개**까지 보관하며 오래된 미수집 드롭부터 제거합니다. 장비는 전투를 자동 중단하지 않고 근처에서 수집합니다. **E / 장비** 버튼에서 비교·장착·교체·버리기가 가능하며 관리 중에는 전투가 멈춥니다. 장비를 장착해도 자동 회복하지 않습니다. 늘어난 최대 체력은 회복으로 채우고, 장비를 벗으면 현재 체력은 새 최대 체력까지만 제한됩니다. 가방은 다음 층에도 유지되고 미수집 드롭은 층 이동 시 정리됩니다.

| 등급 | 표시 | 특수 옵션 | 추가 효과 |
| --- | --- | --- | --- |
| 일반 | 회색 | 없음 | 부위 기본 효과 |
| 희귀 | 파랑 | 서로 다른 1개 | 더 강한 기본 효과 |
| 영웅 | 보라 | 서로 다른 2개 | 더 강한 기본 효과 |
| 전설 | 주황 | 서로 다른 3개 | 고유 공명: 조합 피해 +12% |

기본 효과는 무기=검 피해, 방어구/목걸이=최대 체력, 반지=마법 피해입니다. 옵션은 치명타 확률·피해, 검 속도, 마법 피해, 피해 감소, 체력, 처치 폭발, 대시 후 검격, 저체력 방어, 보스 피해, 속성 마법, 처치 투사체 **12종**입니다. 화산 장비의 속성 옵션은 화염, 설원은 서리에 맞춰 생성됩니다. 전설 공명은 기존 숨겨진 조합 피해에 적용됩니다.

일반 적 장비 드롭은 **1.2%**, 단일 변이 **5%**, 복합 변이 **12%**, 기존 정예 **35%**입니다. 보스는 희귀 이상 장비 3개 중 하나를 고르는 보상을 제공합니다. 가방이 가득 찼거나 원하지 않으면 보상을 건너뛸 수 있습니다. 기존 유물·보스 유산 선택권은 별도로 유지됩니다. 높은 층·유적·공허는 좋은 등급 기회를 늘리며, 1층에서도 전설 확률이 0이 아닙니다.

처치 폭발은 15% 확률·2초 간격·최대 5명, 처치 투사체는 12% 확률·3초 간격·1명입니다. **직접 검/마법 처치**만 이 옵션들을 발동하고 조합·반격 유물·장비 추가 피해는 재발동하지 않습니다. 대시 후 강화는 3초 안 다음 검격 한 번에 +25%. 저체력 방어는 35% 이하에서 옵션당 피해 감소 +6%p, 일반 방어 옵션은 +3%p이며 총 피해 감소 상한 60%입니다. 검 속도 상한은 초당 30회입니다.

### 탐험 NPC 5종

층 진행 **35초 이후 NPC 1명**이 전장에 나타납니다. 지역에 따라 등장 비중이 달라지고, 근처 **3.2m 안에서 R / 교류**로 대화합니다. 대화 중 전투는 멈추며 한 번 선택한 NPC는 다시 사용할 수 없습니다. 포기를 선택할 수도 있습니다.

- **떠돌이 상인:** 희귀 장비·유물 선택권·회복약 중 구매. 비용은 이번 런에 수집한 골드에서 차감하고 **남은 골드만 영구 정산**합니다. 기존 영구 지갑에서는 차감하지 않습니다.
- **수상한 계약자:** 최대 체력 -10%/검·마법 피해 +15%, 적 체력 ×1.15·피해 ×1.1/골드 ×1.25, 회복량 -30%/영웅 장비, 20초 위험 생존/영웅 장비 중 선택. 같은 지속 계약은 중복 제시하지 않습니다. 생존 시간은 실제 전투 시간만 세며 보상은 한 번만 지급합니다.
- **타락한 기사:** 실제 강화 기사와 결투하고 영웅 장비·유물 선택권 획득, 통행료를 내고 30초 피해 축복 획득, 또는 포기. 결투는 일반 적 수 상한을 지키며 반복 처치 보상을 주지 않습니다.
- **잊혀진 대장장이:** 장착품 기본 효과 +12% 강화(최대 5회), 특수 옵션 하나 재설정, 희귀 이상 제작. 장비 기본 효과와 옵션을 즉시 다시 계산합니다.
- **신비한 제단:** 체력 35% 회복, 30초 검·마법 피해 +20%, 강화 정예 2마리 처치 후 영웅 장비 중 선택. 기존 저주 제단과 별도입니다.

화산은 대장장이, 설원은 제단, 숲은 계약자/제단, 유적은 상인/대장장이, 공허는 계약자/기사가 더 자주 나옵니다. 구매·제작의 비용은 해당 층 기본 처치 골드를 기준으로 표시합니다. 가방·골드·강화 한도·적 수 조건이 맞지 않으면 비용을 쓰지 않고 안내합니다.

### 정밀 방어와 반격 (v0.13 도입 당시 · 현재 규칙은 v0.15 참조)

기존 **F 전체화면**을 유지하므로 방어는 **G / 전용 방어 버튼**입니다. 전방 120°에 **0.5초** 동안 자세를 취하고 재사용은 **3초**입니다. 처음 **0.18초**의 적중은 완벽한 패링으로 피해를 무효화하고, 이후에는 받는 피해를 65% 줄입니다. 후방·붉은 지면 위험·독·용암·사후 폭발은 막지 못합니다. 실패에 별도 자원 손실이나 추가 피해를 붙이지 않습니다.

패링 성공 후 **2초 안 다음 검격**은 가장 가까운 전방 단일 대상에게 **2배 피해**를 주며 한 번만 소비합니다. G를 다시 눌러 즉시 검격을 시도하거나 자동 공격을 기다릴 수 있습니다. 보스에게 별도 빙결·무한 경직을 주지 않습니다. `돌진의 뇌심` 유물이 있으면 패링 성공 때 6초 간격의 작은 충격파가 추가되고 재연쇄하지 않습니다. 부분 방어·패링 뒤 흡혈 변이는 실제로 입힌 피해만큼만 회복합니다.

### 무한 심연과 개인 기록

일반 10층 승리 후 **탐험 모드**에서 해금됩니다. 이전 버전에 10층 승리 기록이 있으면 그대로 해금합니다. 심연은 **11층에서 새 런**으로 시작하며 임시 장비는 계승하지 않습니다. 별도 모드의 출발 보정으로 검·마법 피해 ×5, 최대 체력 ×2.5를 적용하고 **층 이동 시 자동 성장·회복은 하지 않습니다**. 기존 영구 강화·캐릭터·시작 무기는 적용됩니다.

모든 층은 기존 120초 생존·보스 처치·경로/지역 선택을 유지합니다. 5층마다 재앙 보스가 추가 체력·피해·보상과 강화 패턴을 사용하고, 20층부터 10층마다 이동 속도·탄환 속도·회복 제한·정예 빈도·위험 빈도·적 원거리 피해 중 제약 하나가 **교대**합니다. 제약은 무한 중첩하지 않습니다. HUD에 설명이 표시되며 방어·이동·대시·회복 빌드로 대응할 수 있습니다.

심연의 층당 체력 ×1.16·피해 ×1.09·기본 골드 ×1.22는 수치 상한 안에서 계산합니다. 일반 적 기본 체력 10¹², 기본 피해 10⁸, 기본 처치 골드 10¹², 보스 체력 5×10¹³, 플레이어 유효 검/마법 피해·최대 체력 10¹⁴, 런 골드/총 획득 골드 10¹⁵에 제한합니다. 적 160마리·적 탄환 80개·마법 효과 100개·마법 투사체 40개·지속 지대 12개 등 기존 상한을 유지합니다.

`voidrun.endgame`에 심연 해금, 최고 층·처치·총 획득 골드·생존 시간, 최고 층 런의 캐릭터·무기·마법·진화·유물·장비와 중복 정산 방지 영수증을 저장합니다. 기존 `voidrun.progression`과 `voidrun.history`를 보존하고 새 필드가 없으면 기본값을 씁니다. 기록·업적 화면은 **이 브라우저 개인 기록**이며 온라인 순위표가 아닙니다. 저장 초기화는 이 새 기록도 함께 지우고 사운드·그래픽·배속 설정은 유지합니다.

| 잊혀진 유적 | ×1.15 / ×1.08 | ×1.20 | 원거리 적·정예 빈도 증가, 수호 상자 +1, 미보유 영웅/전설 유물 선택지 보장 |
| 공허 지대 | ×1.25 / ×1.12 | ×1.55 | 변이·복합 변이 증가, 1.2초 도착 예고 후 일부 적이 순간이동. 상자 공격/궤도 유물 보장 |

상자 보장은 **보유하지 않은 해당 후보가 남아 있을 때 선택지 한 칸을 보장**한다는 뜻이며 자동 획득은 아닙니다. 모든 후보를 수집한 경우 기존 상자 골드를 유지합니다. 보물 경로와 유적의 상자 추가 효과는 더해지며, 최대 4개 상자가 120초 안에 출현할 수 있도록 간격을 조정했습니다. 적 수가 상한에 도달했으면 추가 수호병 출현은 지연됩니다.

화산·숲의 첫 위험 지형은 지역 진입 10초 후 생성되며 이후 각각 14초·18초 간격입니다. 용암은 1.4초 예고 후 반경 2.6m, 독 지대는 1.6초 예고 후 반경 3m에 4초간 남습니다. 지역 위험은 최대 4개이고, 이동·대시로 회피할 수 있습니다. 순간이동은 도착 시점에도 플레이어와 5m 이상 떨어진 걸을 수 있는 위치만 허용합니다. 예고 중 적은 제자리에 머물며, 사망·지역 이동·재시작 시 예고가 정리됩니다.

**몬스터 변이**는 흡혈·폭발·강철·광전사·분열·신속 6종과 두 특성이 결합된 정예 변이입니다. 일반 변이 출현율은 1층 3%에서 10층 24.6%로 증가하며, 공허에서는 최대 34.6%입니다. 화산에서는 폭발형, 숲에서는 분열·흡혈형, 설원·유적에서는 강철형 등이 더 자주 선택됩니다. 보스·소환 하위 개체·분열 자식에는 적용되지 않습니다.

- 단일 변이: 체력 ×1.10, 기존 골드 ×1.45, 경험치 ×1.30.
- 복합 변이: 서로 다른 특성 2개, 체력 ×1.35, 골드 ×2.25, 경험치 ×1.90. 기존 정예와 겹치면 각 보상 배율을 한 번씩 곱합니다.
- 흡혈은 플레이어에게 실제로 준 피해의 45%, 한 번에 자신의 최대 체력 8%까지 회복합니다. 무적 중 빗나간 공격은 회복하지 않습니다.
- 강철은 검·마법 피해를 30% 줄이고 이동이 25% 느립니다. 신속은 이동·돌진 속도 ×1.3입니다.
- 광전사는 체력 35% 이하에서 이동 ×1.3, 원거리·특수 공격 준비 속도 ×1.45입니다. 접촉 공격 재사용은 1.15초에서 약 0.79초로 줄지만 위험 예고와 플레이어 무적 시간은 유지됩니다.
- 폭발형은 처치 후 1초 예고하고 반경 2.8m에 폭발합니다. 예고는 최대 12개이며 플레이어만 공격합니다. 분열형은 약한 자식 2개만 생성하고 기존 분열 적과 중복 분열하거나 자식이 다시 나뉘지 않습니다.

**숨겨진 조합 4종**은 기존 조합 3종에 추가됩니다. 마법 진화는 해당 마법 5단계와 실제 진화 선택을 모두 요구합니다. 해금 알림은 런마다 한 번 표시하고, 이번 런 빌드 도감에서 조건·효과·재발동 제한을 확인할 수 있습니다.

| --- | --- | --- |

조합 피해는 다시 검·룬 적중 조합이나 처치 폭발을 발동하지 않습니다. 추가 타격에 넉백·경직을 붙이지 않으며, 기존 서리의 둔화·쿨다운 제한도 유지합니다.

`src/regions.js`는 지역 선택·적 구성·보상을, `src/region-system.js`는 분위기·위험 지형·지역 적 효과를, `src/mutations.js`는 변이 행동·보상·표식을 관리합니다. `src/game.js`에서 실제 진행·적 생성·피해·상자를 연결하고 `src/magic.js`·`src/synergies.js`에서 조합을 처리합니다. `src/main.js`·`src/style.css`는 선택 화면·지역 표시·도감을 제공합니다. 지역 위험과 사후 폭발의 경계는 언덕 높이에 맞춰 렌더링합니다.

## 공개 주소와 자동 업데이트

GitHub Pages가 활성화되고 배포가 완료되면 게임 주소는 **https://pms0402.github.io/pms/** 입니다.

최초 한 번 [저장소 Settings → Pages](https://github.com/pms0402/pms/settings/pages)에서 **Build and deployment → Source → GitHub Actions**를 선택합니다. Pages를 사용할 수 없는 비공개 저장소/요금제인 경우 GitHub에서 사용 가능 여부를 먼저 확인하세요. 공개 여부는 이 설정에서 임의로 변경하지 않습니다.

그다음부터는 `main`에 업데이트를 푸시할 때마다 `.github/workflows/deploy-pages.yml`이 규칙 테스트와 빌드를 수행하고 같은 주소로 자동 배포합니다. [Actions의 Deploy VOIDRUN](https://github.com/pms0402/pms/actions/workflows/deploy-pages.yml)에서 상태를 확인하고 **Run workflow**로 다시 배포할 수도 있습니다. 배포 실패 시 기존 사이트는 유지됩니다. 채팅에서 파일을 수정한 것만으로 배포되지는 않으며, `main`으로 커밋·푸시해야 반영됩니다.

빌드 결과는 루트와 `/pms/` 하위 경로를 모두 지원합니다. `npm run build` 후 `npm run test:deploy`로 두 경로의 실제 3D 렌더링과 자산 로딩을 검사할 수 있습니다. 배포된 커밋은 사이트의 `version.json`에서 확인할 수 있습니다.

## HTML 미리보기에서 오류가 날 때

원본 `index.html`은 `/src/main.js`와 CSS 등을 서버에서 불러오는 진입 파일입니다. 파일 하나만 보여주는 채팅의 HTML 미리보기에서는 다른 파일을 찾지 못해 실행되지 않을 수 있습니다. 공개 사이트가 아직 활성화되지 않았다면 해당 미리보기를 게임의 공개 주소로 사용할 수 없습니다.

외부 자산 요청 없이 실행되는 단일 HTML 파일은 아래 명령으로 만듭니다. `standalone/VOIDRUN.html`에 게임 JS·CSS·favicon이 포함되며, 글꼴은 시스템 글꼴을 사용합니다. `npm run test:standalone`은 HTML 하나만 제공하는 서버와 격리된 iframe에서 3D 렌더링·조작을 검증합니다. 실제 채팅 서비스의 시각화 정책에 따라 실행이 제한될 수 있습니다.

```sh
npm run build:standalone
npm run test:standalone
```

자동 배포에도 단일 파일을 포함하므로 Pages 배포 완료 후에는 `https://pms0402.github.io/pms/VOIDRUN.html`로 열 수 있습니다. 기본 게임 주소는 계속 `https://pms0402.github.io/pms/` 입니다.

## 플레이

- WASD / 방향키: 화면 기준 이동
- Space: 3초 쿨다운의 무적 대시
- Escape: 일시정지 / 계속
- 공격: 자동 검격 + 습득한 마법의 자동 시전 (화염구 1단계로 시작)
- 레벨업: 카드 클릭 또는 숫자 1–4로 강화 선택. 유물·보스 선택권이 있으면 네 번째 카드 추가
- B / 이번 런 빌드 버튼: 이번 런의 마법·진화·임시 강화 확인
- F / G: 전방 패링과 성공 후 광역 반격.
- Shift+F / 전체화면 버튼: 전체화면 전환. 전체화면 API를 지원하지 않는 Safari에서는 전장을 화면에 맞춰 확장하며 같은 버튼으로 돌아옵니다.
- 상단 영구 강화 / 보유 골드 버튼: 사망 후 회수한 골드로 다음 런의 기본 능력치 구매
- 마법 슬롯 / 빌드 정보 버튼: 보유 마법·진화·이번 런의 강화 정보 확인
- 모바일: 화면 방향 버튼 또는 전장 드래그로 이동, 번개 버튼으로 대시

최소 120초짜리 **10개 층**을 돌파하면 승리합니다. 각 층 90초에 보스가 한 번 등장하며 **120초 생존과 보스 처치가 모두 필요**합니다. 시간이 끝나도 보스가 살아 있으면 전투가 계속됩니다. 5층은 중간 지점이며, 10층의 마지막 보스를 처치해야 승리합니다. 각 층의 이름·분위기·등장 비중이 바뀌고, 후반에는 강화된 보스 패턴이 추가됩니다.

플레이 가능한 반경은 90으로, 이전 반경 62 맵보다 **면적이 약 2.1배** 넓어졌고 카메라가 플레이어를 완전히 따라갑니다. 초반은 드문 출현을 유지하고 후반에는 군단이 등장합니다. 일반 몬스터는 성능을 위해 최대 160마리로 제한하며, 보스가 추가로 등장할 수 있습니다.

플레이어 능력치는 **레벨업에서 직접 고른 카드**, **보물상자에서 직접 고른 유물**, **런 종료 후 구매한 영구 강화**로 성장합니다. 층 이동이나 보스 처치만으로 공격력·최대 체력·속도·범위 등이 오르지 않으며, 층 이동 시 현재 체력도 그대로 이어집니다. 검과 마법은 별도로 성장하고 선택한 레벨업 강화는 검/마법 공격력 ×1.2, 해당 공격 속도 ×1.08, 최대 체력 ×1.15로 복리 적용됩니다. 이동 속도 +3%, 획득 범위 +8%, 치명타·피해 감소 +2%p, 초당 최대 체력 재생 +0.2%도 선택할 수 있습니다. 체력 증가 카드를 직접 고르면 증가한 최대 체력만큼 회복합니다.

적은 층마다 체력 ×1.7·피해 ×1.35로 강해지며, 획득 경험치는 1층 ×1에서 10층 ×2.8로 증가합니다. 후반의 다양한 적·보스 패턴과 군중을 상대하며 레벨업 선택으로 빌드를 키웁니다.

## 유물·탐험·위험 계약

수호 보물상자는 수호병 셋을 처치한 뒤 다가가면 골드를 즉시 지급하고, **유물 3개 중 하나를 바로 고르게** 합니다. 레벨업이나 경험치는 필요하지 않으며, 고른 유물만 한 번 적용됩니다. 이미 모든 유물을 소유했다면 골드만 지급하고 전투를 계속합니다. 정예는 **유물 선택권**을 지급합니다. 획득 즉시 능력치가 변하지 않고, 정예 선택권은 다음 레벨업에 나오는 추가 카드에서 직접 고른 유물만 적용됩니다. 기본 마법·검술·생존 카드 대신 유물을 고르면 선택권 한 장이 소비되며, 기본 강화를 고르면 선택권은 남습니다. **총 28종**에는 검·마법 피해와 속도, 사거리·범위, 마법별 추가 피해, 정예·보스 추가 피해, 체력·방어·재생, 이동·자석·경험치·골드 배율, 일회 부활, 대시 충격파가 있습니다. **서리불꽃**은 둔화된 적에 대한 화염구 피해를, **폭풍의 문양**은 번개와 궤도 룬을 함께 사용하는 빌드를 강화합니다. 유물은 중복 획득되지 않고 다음 런에 초기화됩니다. 도망치는 황금 몬스터는 제한 시간 안에 추격해 잡아야 높은 골드를 얻습니다.

시작 전 위험 계약을 선택할 수 있습니다. 추가 골드에는 적 강화가 함께 붙으며 런 도중 바꿀 수 없습니다.

| 계약 | 골드 배율 | 적 체력 | 적 피해 | 속도 | 출현 빈도 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기본 탐험 | ×1 | ×1 | ×1 | ×1 | ×1 |
| 군세의 계약 | ×1.8 | ×1.3 | ×1.15 | ×1 | ×1.4 |
| 광란의 계약 | ×2.2 | ×1.65 | ×1.4 | ×1.08 | ×1.1 |

**탐욕의 인장** 유물도 골드 +15%에 이후 출현하는 적 체력 +15%·모든 적 피해 +10%를 함께 부여합니다. 영구 강화로 얻은 전투 능력치에 맞춰 적을 자동으로 키우지는 않습니다. 정예는 높은 체력과 피해를, 상자는 수호병 전투를 요구합니다.

새 **연금** 유물의 골드 +30%에는 이후 적 체력 +20%·모든 적 피해 +15%가 붙습니다. 기본 골드 수입은 이전의 5배로 늘었으며, 위험 계약 보너스는 여기에 별도로 적용됩니다.

보스 처치 시 골드·경험치와 고유 유산 선택권을 얻습니다. 검 범위·피해·독 폭발·마법 피해·최대 체력·공격 속도·치명타·방어·추가 표적·골드 보정 등 유산 효과도 **레벨업 카드로 선택한 뒤에만** 적용됩니다. 10층의 왕관도 자동 능력치 보너스를 주지 않습니다.

| 마법 | 공격 방식 | 5단계 후 진화 |
| --- | --- | --- |
| 화염구 | 가까운 적을 추적하고 폭발 범위 피해 | 태양의 격노: 3연발 + 잔류 폭발 |
| 서리 파동 | 주변 피해 + 1.4초간 40% 둔화 | 영원의 눈보라: 1.8초간 55% 둔화 + 짧은 약한 둔화 장판 |
| 연쇄 번개 | 적 사이를 도약하며 공격 | 폭풍의 심판: 가지치는 번개와 추가 표적 |
| 궤도 룬 | 몸 주변을 회전하며 충돌 피해 | 공허의 성좌: 추가 룬 + 확대 궤도 + 광역 파동 |

레벨업에는 습득·강화·진화할 마법이 남아 있다면 반드시 마법 선택지가 포함됩니다. 이 임시 강화와 마법은 새 런에서 초기화됩니다.

## 사망 → 골드 회수 → 영구 강화 → 재도전

런 도중 수집한 골드는 사망하거나 완주하면 영구 지갑에 정산됩니다. 결과 화면의 **영구 강화하고 재도전**을 눌러 다음 런을 준비하세요. 일시정지 메뉴의 **런 종료하고 골드 회수**로 직접 종료해도 수집한 골드를 보관합니다. 진행 중인 창을 새로고침하거나 닫는 것은 정산이 아니므로, 종료 메뉴를 먼저 사용하세요.

| 영구 강화 | 1단계 효과 | 첫 가격 | 최대 단계 |
| --- | --- | ---: | ---: |
| 검술의 뿌리 | 검 공격력 ×1.12 | 12 G | 50 |
| 연속 베기 | 검 공격 속도 ×1.025 | 18 G | 40 |
| 검기의 가지 | 검 범위 +2% | 20 G | 20 |
| 마력의 뿌리 | 마법 공격력 ×1.12 | 12 G | 50 |
| 주문의 흐름 | 마법 시전 속도 ×1.025 | 18 G | 40 |
| 확산의 가지 | 마법 범위 +2% | 20 G | 20 |
| 생명의 뿌리 | 기본 최대 체력 ×1.10 | 15 G | 50 |
| 견고한 피부 | 기본 피해 감소 +0.75%p | 24 G | 40 |
| 잔향 자석 | 기본 획득 범위 +3% | 10 G | 30 |
| 황금의 운 | 골드 획득량 +5% | 20 G | 30 |

처음 5단계의 가격은 유지하고, 이후에는 후반 골드 수입에 맞춰 비용이 크게 증가합니다. 검 공격력 기준 10단계 구매는 3,000G, 20단계 30만G, 30단계 3,000만G, 40단계 30억G, 마지막 50단계는 3,000억G입니다. 최대 단계가 다른 강화도 해당 트리의 진행도에 맞춰 후반 가격이 상승합니다. 능력치 효과와 기존 구매 단계·보유 골드·정산 기록은 유지됩니다. 예를 들어 1,000G를 공격·마법·체력·양쪽 속도에 나눠 쓰는 정해진 구매 순서에서는 강화 30회, 양쪽 DPS 약 2.29배·체력 1.77배의 초기 성장이 가능합니다. 구매는 런 사이에만 가능하며 구매한 능력치는 다음 런 시작 때 적용됩니다. 기존 구매 단계는 보존되고 강화된 새 효과를 받습니다. 영구 골드와 강화 단계는 사망·재도전·새로고침 후에도 같은 브라우저에 남습니다. 런마다 고유 정산 ID로 중복 지급을 막고, 기존 버전의 완료된 런 기록에 남은 골드도 첫 실행 시 한 번 이전합니다.

야영지에서 중심 노드 → 검·마법 가지로 이어지는 트리를 사용합니다. 검 계열 자식은 검술의 뿌리 1단계, 마법 계열 자식은 마력의 뿌리 1단계가 필요합니다. 이전 버전에서 구매한 강화와 골드는 그대로 유지됩니다.

같은 영구 지갑으로 비전술사·광전사와 질풍검·파쇄 대검을 해금하고 다음 런 장비로 선택할 수 있습니다. 전문 캐릭터는 다른 공격 계열이나 체력을, 빠른 검과 무거운 검은 공격력이나 속도를 교환하므로 일방적인 상위 장비가 아닙니다.

계정 동기화용 서버는 없으므로 다른 기기·브라우저로 자동 공유되지 않습니다. 저장소를 사용할 수 없는 미리보기에서는 실제 저장 불가 안내를 표시하고, 창을 닫으면 기록이 사라집니다. 브라우저 데이터를 삭제해도 영구 기록이 초기화됩니다.

효과음·그래픽 설정과 최근 30개 런 기록은 현재 브라우저의 localStorage에 보관됩니다. 브라우저 데이터를 삭제하면 초기화됩니다. 사운드는 기본으로 꺼져 있으며 오른쪽 위 스피커 버튼으로 켤 수 있습니다. WebGL 2와 하드웨어 가속을 지원하는 브라우저가 필요합니다.

v0.4는 배경 인스턴싱, 적 모델 병합, 적·이펙트·피해 숫자 재사용과 근거리 공간 검색을 사용합니다. 이전 버전과 같은 160마리 배치·1000×700 투영·높음 설정에서 렌더링 호출은 1,240회에서 558회로 약 55% 줄었습니다. 기본 그림자·해상도 설정은 유지되며 이 수치는 기기별 FPS 향상을 보장하는 값은 아닙니다. 전장은 현재 화면에 맞추고, 강화·가이드 창만 내부에서 스크롤합니다.

v0.5의 보스 체력 바는 전장 맨 위에 높이 약 30px로 표시되며, 큰 패널과 설명 문구가 전투 중앙을 가리지 않습니다.

## 검 진화·조합·탐험 선택 (v0.8)

기본 검의 실제 타격 거리는 **2.8m**, 전방 **120°**입니다. 화면의 검격 부채꼴과 충돌 판정은 같은 거리·각도를 사용하며, 검격은 판정 밖으로 커지지 않고 사라집니다. 레벨업의 **뻗어가는 칼끝**는 범위를 단계마다 ×1.12, 최대 8회 늘립니다. 캠프의 검 범위 강화와 유물도 함께 적용됩니다. 층 이동만으로 범위가 늘지는 않습니다.

검 공격력·공격 속도·범위 강화 합계 3단계부터, 레벨업 선택에 세 검 진화가 열립니다. 한 런에서 하나만 고를 수 있습니다.

| 검 진화 | 변화 |
| --- | --- |
| 거인의 대검 | 전방 180°, 피해 ×1.35, 공격 속도 ×0.78 |
| 질풍의 쌍검 | 전방 100°, 공격 속도 ×1.75, 피해 ×0.72, 범위 ×0.9 |
| 공허의 검기 | 전방 45°, 범위 ×1.8, 피해 ×1.05, 공격 속도 ×0.85 |
