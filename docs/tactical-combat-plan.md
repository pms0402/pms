# VOIDRUN v0.20 개발·검증 계획

기준: v0.19.3 (`4e30a9d`). 수동 공격·연속 회전·기존 콘텐츠와 저장 데이터는 보존한다.

1. 전투 판정: 선분/장애물 교차, 피격 반경, 설치/투사체 조준과 예고를 같은 데이터로 연결한다.
2. 선택형 락온: 안정적인 단일 타깃, 명시적 전환/해제, 측면/후진, 보스 추적, PC/모바일 입력과 키 호환.
3. 액션: 대시 종료 시 예약 공격, 무기별 회복/버퍼, 제한된 회복 취소, 명확한 자세 표시.
4. 전투 연계: 서리→강공격, 화염→검, 대시→번개, 패링→마법. 숨겨진 진화 조합과 별도 수명·쿨다운·통계를 사용한다.
5. 보스/압박: 실제 위치·거리·공개된 회복 동작을 관찰하고 입력은 읽지 않는다. 안전 통로·예고·확정 회복과 페이즈 연계를 유지한다.
6. 층 목표: 정예·방어·돌파·봉인·추적·소환 의식. 첫 층/최종 층의 기존 생존 흐름과 분기/보상/스토리를 보존한다.
7. 훈련장: 야영지에서 격리된 실제 전투 시뮬레이션. 콤보/차징/스킬/회피/패링/몬스터/만난 보스를 연습하며 실제 지갑·기록·쿨다운을 보존한다.
8. 검증: 단위·실제 WebGL·네이티브 키/터치·3시점·지역/보스/방 왕복·이전 저장·무입력 비발동·자원 상한·배포/독립 HTML.

완료 보고에는 구현 파일·연결된 동작·밸런스와 측정 조건·실제 통과한 검사·남은 제한을 기록한다. 기능은 화면에 표시하는 것으로 완료하지 않는다.
