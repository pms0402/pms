# VOIDRUN v0.19 수동 액션 전환

기준: v0.18.0 `dc1d698`. 기존 저장 키/골드/강화 단계/해금/기록과 콘텐츠는 유지한다. 기존 태그로 이전 버전을 보관한다.

현재 `Game.tick`의 자동 검격, `MagicSystem.update`의 자동 세 마법과 상시 궤도 접촉, `Parry.press`의 자동 반격 예약을 제거한다. 캐릭터를 가장 가까운 적에게 돌리는 공격 코드를 제거한다. 공격 피해는 입력 시점이 아닌 애니메이션의 접촉 마커에서 적용한다.

- 공통 액션 상태: 준비/접촉/회복, 0.18초 입력 버퍼, 3타/5타 콤보, 차징, 한 번만 실행하는 타격 마커. 공속은 제한된 모션 가속이며 무한 클릭으로 회복을 건너뛰지 않는다.
- 검 기본 피해 계수 ×2.2, 마지막 타격 추가 배율. 강공격 4초. 대검 차징 최대 1.2초, 검기 관통, 쌍검 마지막 3회 타격. 정확한 범위는 같은 profile을 이펙트와 판정에 사용한다.
- Q/E/R 일반 슬롯 3개: 배운 마법 중 배치/교체. 보관된 마법 레벨/진화/조합 조건을 삭제하지 않는다. X 궁극기는 활성 스킬의 속성을 묶은 공허 붕괴(45초). 신규 레벨업은 피해 외 범위/추가 타격/시전/제어를 선택한다.
- 불 12초, 서리 14초, 번개 10초, 설치 룬 18초. 마법 가속은 준비 단축과 제한된 재사용 감소로 변환한다. 지속 피해/소환수/유물/세트의 조건부 효과는 직접 입력한 공격에서 시작하며 독립 자동 시전은 없다.
- 평시 5~15, 후반/심연 15~25 동시 개체 목표. 이벤트/소환은 기존 160 절대 상한을 보존한다. 경험치/골드는 줄어든 빈도에 맞게 보정한다. 적은 측면/포위·예고 근접 공격·회복 빈틈을 사용하고 AI는 관측 가능한 위치/공격 동작만 읽는다.
- 보스는 거리/이전 행동/페이즈로 공격을 고르고 공격 후 회복 시간을 제공한다. 숨겨진 보스/페이즈/패링 불가 지형 위험은 보존한다.
- 기본: 좌/우 클릭, Q/E/R/X, Shift, F, WASD, Tab, ESC. 교류 C, 빌드 B, 시점 V, 전체화면 버튼/F10. 키 충돌을 검사하는 저장 가능한 재지정. 모바일 조이스틱·공격/차징/기술 버튼과 크기/위치 설정.
- PC 1/3인칭: 전장 클릭으로 마우스 잠금, 미지원/해제 상태는 중간 버튼 드래그와 포인터 조준. 항공은 포인터 지면 조준. 마우스 좌/우 버튼을 시점 드래그로 중복 소비하지 않는다.

검증은 무입력 무피해, 조준 방향, 실제 접촉 마커, 입력 버퍼/반복키/차징 취소, 슬롯/쿨타임/진화/조건부 조합, AI 예고와 회복, 실제 브라우저 PC/모바일/세 시점, 기존 저장/전투 통계/콘텐츠를 포함한다. 자동 공격 전제 테스트는 수동 입력과 시간 진행으로 수정하며 구버전 보관 검사는 그대로 둔다.
