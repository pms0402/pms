# v0.20.2 공격 중 자유 시점·검격 추적

공격 중에도 시점·캐릭터 방향을 즉시 갱신하고 현재 검격 방향 벡터를 같은 방향으로 바꾼다. 공격 종료 후 누적 조준을 한 번에 적용하던 처리를 제거했다. 터치 이동 선회도 공격 도중 계속 작동하며, 모델의 방향 보간 상태를 맞춰 공격을 마친 뒤 몸이 이전 방향으로 돌아가지 않게 했다.

일반 검·차징 대검·쌍검·패링 반격의 각 타격 시점에서 최신 방향을 사용한다. 타격 시점·횟수·회복·쿨타임·피해·사거리는 유지한다. 이미 발생한 타격을 방향 변경으로 다시 실행하지 않으며, 발사된 검기는 독립된 진행 방향을 유지한다. 마법의 이미 선택한 시전 위치도 유지하면서 시점 자체는 자유롭게 돌릴 수 있다.

변경 파일: `src/action-combat.js`, `src/game.js`, `src/creatures.js`, `src/combat-aim.js`, `src/main.js`, 관련 테스트·package.json·README. 저장 데이터·영구 강화·그래픽 품질은 바꾸지 않는다.

검증: 단위 테스트 **237/237**, 관련 Chromium WebGL 스위트 **10/10**, 프로덕션·독립 HTML 빌드. [검증 기록](live-sword-verification.json).

새 검사는 실제 포인터 잠금 상태에서 마우스를 움직이며 1·3인칭 × 일반 검/차징 대검/쌍검의 6개 시나리오를 실행한다. 공격 중 각 프레임의 카메라·캐릭터·검격 방향 일치, 준비 중 무피해, 돌린 쪽 실제 적중·이전 방향 미적중, 원래 타격 횟수와 공격 종료 뒤 시점 변화 0을 확인한다. 항공 시점의 공격 중 포인터 조준, 발사된 검기 독립성, 모바일 실제 오른쪽 터치와 공격 중 이동 선회도 검증한다. 기존 조작·자동 잠금·패링·보스·연계·모션/군중·훈련·저장·독립 HTML 검사도 함께 실행한다.

실제 iPad/Safari의 장치별 프레임과 조작감은 Chromium 터치 에뮬레이션 검사와 별개다.
