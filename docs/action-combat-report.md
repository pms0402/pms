# VOIDRUN v0.19.0 수동 액션 전환 보고서

기준은 v0.18.0 (`dc1d698`)입니다. 자동 전투를 직접 조작하는 전투로 전환하며, 기존 10층·분기 지역·보스·변이·장비·직업·영구 강화·지갑·기록·야영지·던전·스토리·심연과 저장 키를 유지합니다. 이전 버전은 `v0.18.0` 태그와 v0.16.0 고정 HTML로 보존합니다.

## 조작

| 기본 입력 | 동작 |
| --- | --- |
| WASD, 방향키 | 시점 기준 이동. 항공 시점은 기존 지면 기준 |
| 좌클릭 / 우클릭 | 일반 공격 / 강공격. 대검은 우클릭을 누르고 충전한 뒤 놓기 |
| Q / E / R | 장착한 일반 스킬 3개 |
| X | 조준 위치에 궁극기 ‘공허 붕괴’ |
| Shift / F | 대시 / 패링. 패링 성공 후 2초 안에 직접 검 공격으로 반격 |
| Tab / B | 장비·캐릭터 / 스킬 배치·빌드 도감 |
| C / V / F10 | 근처 NPC·야영지·던전 교류 / 시점 변경 / 전체화면 |
| ESC | 일시정지·선택 창 닫기. 마우스 잠금 해제 시 전투도 일시정지 |

1·3인칭은 전장을 클릭하면 마우스를 잠가 조준합니다. 잠금이 지원되지 않으면 가운데 버튼 드래그로 둘러보고 포인터로 지면을 조준할 수 있습니다. 항공 시점은 포인터 조준입니다. 1·3인칭에서 위아래 시선으로 설치 위치의 거리를 조정합니다. 공격 중에는 입력 당시 방향을 유지해 뒤로 돌며 이미 시작한 검격을 옮기지 못합니다.

설정에서 물리 키·마우스 버튼을 재지정할 수 있으며 중복 배치는 거절합니다. 한글 IME의 Q/E/R/F/WASD/V도 물리 키로 인식합니다. 모바일은 왼쪽 가상 조이스틱·방향 버튼, 오른쪽 드래그 시점, 일반/강공격·대시·패링·4개 스킬 버튼을 제공합니다. 버튼 크기와 오른쪽·위 여백을 설정에 저장합니다.

## 실제 전투 변경

`Game.tick`의 자동 검격, `MagicSystem.update`의 자동 마법, 플레이어 몸을 도는 상시 룬 공격을 제거했습니다. 적이 앞에 있어도 입력하지 않으면 검·마법이 발동하지 않습니다. 가까운 적을 골라 플레이어를 자동 회전시키지 않습니다. 소환수도 직접 입력한 공격/마법의 지령 후 짧은 전방 보조만 합니다. 장비·세트·조합의 조건부 추가 피해는 수동 적중에서만 시작하며, 지속 피해는 직접 시전한 지대가 끝날 때 종료됩니다.

검은 준비 → 접촉 마커 → 회복을 따릅니다. 입력 직후에는 피해가 없으며 접촉 시점에서 한 번만 판정합니다. 회복 마지막 0.18초의 입력 하나를 버퍼에 보관합니다. 초기 연타로 회복을 생략할 수 없고 키 반복도 새 공격으로 처리하지 않습니다. 대시·패링으로 자세를 취소할 수 있지만 지급한 강공격/스킬 쿨다운은 돌려주지 않습니다. 장비 교체·씬 전환은 남은 액션을 정리합니다.

| 무기 | 동작 |
| --- | --- |
| 일반 검 | 3타, 좌우 베기와 마무리 자세. 마지막 타격 피해 ×1.65와 넉백 |
| 대검 | 느린 180° 베기, 일반 사거리 ×1.15. 강공격 충전 최대 1.2초, 놓을 때 발동, 일반 적 0.5초·정예 0.25초 자세 붕괴 |
| 쌍검 | 빠른 5타. 마지막 3개 접촉 마커에 각각 ×0.68 피해. 대시 직후 첫 연계만 모션 15% 단축 |
| 공허 검기 | 조준한 직선으로 날아가는 검기. 일반 폭 1.5m·7명 관통, 강공격 폭 3.6m·12명 관통. 벽과 최대 사거리 제한 |

검 기본 타격 계수는 기존 검 능력치의 ×2.2입니다. 일반 기본 모션은 약 0.54초, 쌍검 0.37초, 대검 0.84초이며 무기 진화·기존 공속을 제한적으로 반영합니다. 검 모션 가속은 최대 1.65배, 시전 준비 가속은 최대 1.6배입니다. 이미 구매한 가속 단계는 삭제하지 않습니다. 강공격은 4초, 피해 ×(2.1 + 충전량 ×1.8), 일반 사거리 ×1.3입니다.

검 궤적·지면 부채꼴·검기 통로는 실제 액션의 방향/범위와 같은 데이터를 사용합니다. 적의 충돌 반지름이 경계에 닿으면 타격할 수 있습니다. 대검과 쌍검의 모든 접촉 마커에 검의 접촉 자세가 맞도록 모션 시간을 재매핑했습니다. 범위 표시용 고정 버퍼 하나를 재사용합니다.

## 스킬·성장·패링

| 스킬 | 기본 재사용 / 준비 | 역할 |
| --- | --- | --- |
| 화염구 | 12초 / 0.42초 | 직접 조준, 기본 반경 6m 폭발·4초 화염 지대. 진화하면 부채꼴 3발과 여진 |
| 서리 파동 | 14초 / 0.50초 | 기본 반경 9m. 2.2초 동안 50% 둔화, 일반 적 짧은 빙결. 진화하면 4초의 약한 눈보라 |
| 연쇄 번개 | 10초 / 0.30초 | 전방 22m·너비 4.4m 안에서 첫 적중 후 연쇄. 빗나가면 쿨다운을 소비 |
| 설치 룬 | 18초 / 0.62초 | 조준 위치의 기본 반경 5.5m 마법진. 6초 지속 피해·약한 둔화, 진화하면 종료 폭발 |
| 공허 붕괴 | 45초 / 0.85초 | 조준 위치 반경 11m. 장착한 스킬 수로 피해 강화, 화염/서리 속성 반영 |

마법 단계·진화·영구 범위·유물·장비·세트 효과를 반영합니다. 재사용 최소값은 불/번개 8초, 서리 10초, 룬 14초입니다. 효과 반경은 최대 20m입니다. 시전 중 이동은 불 40%·서리 65%·번개 35%·룬 25%·궁극기 15%이며, 시전 전 실제 피해를 받으면 취소됩니다. 룬·화염 지대·눈보라는 유한 수명과 틱 간격을 유지합니다. 서리의 일반 빙결은 기본 0.35초, 강화해도 0.6초, 같은 대상 재빙결 간격은 6초이며 보스에게 적용하지 않습니다.

3개 슬롯 외 배운 마법도 단계·진화·조합 조건을 유지합니다. 네 번째 마법을 배우면 즉시 교체/보관을 선택하며, B에서 다시 배치할 수 있습니다. 교체와 던전 왕복으로 이미 사용한 기술의 쿨다운을 초기화할 수 없습니다. 레벨업에 범위 ×1.12, 추가 투사체·연쇄/여진, 상태 지속 강화 선택을 추가했습니다. 층을 넘는 것만으로 플레이어 능력치가 증가하지 않습니다.

완벽한 패링의 판정·0.1초 히트 스톱·4m 충격파·경직 저항·보스 공격 취소는 유지합니다. 성공 후 2초 안의 수동 검 공격이 ×2.5 부채꼴 반격을 한 번 사용합니다. 일반 검 배율과 중복 계산하지 않으며 반격 피해는 별도 통계로 기록합니다. 반격을 빗맞혀도 소비한 반격은 돌아오지 않습니다. 대시는 2.4초 재사용·0.28초 피해 무효화이며 이동과 취소의 역할을 담당합니다.

## 적·보스와 보상

일반 전투 동시 개체 목표는 5~15, 계약/심연의 높은 압박은 최대 25입니다. 상자 수호자·보스 소환·분열 등의 이벤트는 이를 넘을 수 있으나 기존 절대 상한 160을 지킵니다. 근접 공격 동시 준비는 초반 2명·후반 3명·심연 4명으로 제한합니다.

기본 근접 적·사냥꾼·거인·분열체는 측면 접근 → 방향을 고정한 푸른 부채꼴 예고 → 단발 타격 → 회복을 수행합니다. 단순 접촉만으로 피해를 주지 않습니다. 예고 0.52~0.86초, 회복 0.55~1.55초를 개체/정예/변이에 맞게 사용합니다. 가벼운 검 적중으로 공격을 끊을 수 있지만 같은 적을 계속 멈추지 못하도록 2초 저항을 둡니다. 정예는 실제 대시가 끝난 움직임과 보이는 방어 자세를 관찰합니다. AI는 입력 키를 읽지 않습니다. 원거리 사선·돌진·자폭·치유·변이 패턴은 유지합니다.

보스는 거리와 직전 행동을 이용해 근접/원거리 패턴을 고르고, 공격 뒤 약 0.8~1.25초의 반격 기회를 제공합니다. 회복 중 받는 피해는 ×1.2입니다. 기존 보스 6계열·10층 변형·3페이즈·히든 보스·붉은 패링 불가 지형 위험을 유지합니다.

기본 일반 적 체력 28 → 50, 피해 7.5 → 11로 조정했습니다. 층별 체력 ×1.7·피해 ×1.35, 기본 코인 ×10 곡선과 120초 생존/90초 보스 조건은 유지합니다. 처치 빈도가 낮아진 만큼 실제 처치 경험치는 ×3, 골드는 ×2.5입니다. 영구 강화 가격·지갑·해금 비용은 바꾸지 않습니다. 상자 보상과 지역/계약 추가 보상을 유지합니다.

## 검증 방법과 한계

**단위 테스트 206/206, 고유 브라우저 스위트 30/30 통과**. 프로덕션·독립 HTML 빌드, 루트와 `/pms/` 배포 경로, 독립 HTML의 격리 iframe 실행을 통과했습니다. [스위트별 최종 결과와 재실행 기록](action/verification.json)에 실패한 초기 시도와 이후 통과를 함께 남겼습니다. 기존 자동 전투를 되살려 검사를 통과시키지 않았습니다. 기존 전투 도메인 fixture는 직접 방향과 공격 명령을 지정한 뒤 실제 접촉 마커까지 시간을 진행하도록 수정했습니다. 이는 프로덕션 코드를 교체하지 않으며, 실제 키/클릭·입력 버퍼·피해 지연·무입력 비발동은 별도의 새 브라우저 검사에서 검증합니다.

- 새 네이티브 입력 검사: 클릭을 놓은 뒤의 입력 버퍼, 실제 우클릭 차징/해제, 모바일 강공격 예약 유지, 12초 무입력 상태에서 진화 4종이 있어도 공격/시전/상시 룬 없음, 클릭 방향과 실제 접촉 프레임, Q/E/R 단축키 충돌 방지, 슬롯·궁극기·재지정 저장, 3시점, 실제 모바일 탭.
- 새 전투 통합 검사: 실제 거인 접근·예고·타격·회복, 회피, 협공 허용 수, 네 번째 마법 교체·보관, 차징 접촉/자세 붕괴, 마우스 잠금/ESC, 기존 저장 대조.
- 기존 검사: 모든 지역·변이·숨겨진 조합·보스 페이즈·장비·세트·직업·성역/던전·스토리·상자·정산·영구 강화·심연·사운드·리소스·배포 경로·단독 HTML·고정 v0.16.0을 포함합니다.
- 렌더링은 Chromium/SwiftShader입니다. 실제 모바일 Safari·iPad의 FPS·발열·동시 터치 감각까지 검증한 결과로 해석하지 않습니다. 기존 GPU 인스턴싱·LOD·PBR과 파티클/투사체/지대 제한은 유지합니다.
- 고정 빌드 전투는 실제 체력·쿨다운·AI를 사용하는 입력 스크립트로 측정합니다. 모든 직업·유물 조합의 완주율과 장시간 소모전을 인간 플레이로 검증하지 못했습니다. 후반 보스와 심연은 계속 조정이 필요한 영역입니다. 기능 테스트 통과와 난이도 완벽 검증을 구분합니다.


### 실제 밸런스 측정

[원본 고정 빌드 전투 기록](action/balance-duels.json)은 1/5/10층 각각 일반·정예·보스를 실제 체력으로 상대합니다. 선택 카드로 구성한 빌드와 검/마법/체력 영구 강화 0/5/12단계를 사용합니다. 별도 무적·적 체력 축소·플레이어 체력 부풀리기는 사용하지 않습니다. 스크립트는 눈에 보이는 예고에 반응해 이동/대시하며 수동 액션 명령을 냅니다. 랜덤 보상과 한 런 전체의 소모전은 포함하지 않습니다.

| 1층 | 3 | 보스 체력 약 9.0%에서 사망 | 18.26초 |
| 5층 | 3 | 처치, 플레이어 체력 약 37 남음 | 36.98초 |
| 10층 | 3 | 보스 체력 약 18.5%에서 사망 | 26.70초 |

기록에서 일반 적은 0.56초, 정예는 1.02~1.32초에 강한 스킬로 처치했습니다. 5층 보스는 3페이즈를 거쳐 36.98초에 처치했습니다. 10층 보스는 3페이즈·남은 체력 약 18.5%에서 입력 스크립트가 사망했습니다. 단순 공격 우선 스크립트가 모든 보스를 안정적으로 이긴다는 결과가 아니며, 전 직업/유물 조합의 후반 완주율 검증은 남아 있습니다. 보스 예고·페이즈별 발동/회피·경직은 별도 기능 검사에서 확인합니다.

### 성능과 저장 보존 근거

[160마리 렌더 비교](action/render-comparison.json): 같은 선택 메시 401,562 삼각형을 CPU 개별 렌더와 GPU 인스턴싱으로 비교했습니다. 드로 콜 774 → 191, 평균 RGB 오차 0.000714/255, 3단계 이상 달라진 픽셀 비율 약 0.0067%였습니다. 모델·PBR 재질·그림자를 유지하며 서로 다른 프레임의 FPS 비교가 아닙니다.

[16회 지역/런 초기화](action/resource-stress.json): 다섯 지역·복합 변이·보스 등 콘텐츠를 예열한 뒤 GPU 기하 163·텍스처 18·배치 37·LOD 원본 37로 유지됐습니다. 후반 8회 보유 힙은 약 29.9~30.1MB, 남은 CPU 포즈 캐시는 0개였습니다. 소프트웨어 렌더러 수치를 실기기 FPS로 환산하지 않습니다.

저장 검사는 기존 지갑 123,456,789G·검/마법/체력/가속 강화·캐릭터/무기 해금·선택 장비·정산 ID를 넣고 새 입력과 스킬 교체 후 같은 저장 값을 대조합니다. 기존 고단계 구매·기록·초기화·한 번만 정산·직업·스토리 저장 검사도 유지합니다. 고정 v0.16.0 HTML의 SHA-256은 `e8867949d23b1319d9f111432b4ce02f6982fca30ea40d564bc76b1d31b019aa`로 보존합니다.

진행/경제 도메인 검사의 일부는 소프트웨어 GPU 대기를 줄이기 위해 논리 뷰포트를 유지한 0.5배 렌더 버퍼를 사용합니다. 네이티브 입력·모바일 레이아웃·동일 픽셀 비교·품질/재질·160마리 스트레스 검사는 기존 해상도에서 실행하며, 게임의 배포 품질 설정을 낮추지 않습니다.
