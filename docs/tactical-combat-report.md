# VOIDRUN v0.20.0 수동 전투 확장 보고서

기준 버전: v0.19.3 (`4e30a9d`). 이전 태그와 v0.16.0 고정 실행본을 보존한다.

## 추가된 기능과 실제 연결

### 선택형 락온과 이동

- 기본 키 L로 선택/해제, K/J로 다음/이전 대상. 설정에서 바꿀 수 있으며 기존 사용자 키와 충돌하면 새 기능만 빈 키를 배정한다. 모바일 상단의 락온·전환 버튼도 같은 명령을 호출한다.
- 26m 안의 보이는 적을 선택하며 보스에 우선 점수를 준다. 선택 후 다른 적의 생성/근접 때문에 대상을 자동 변경하지 않는다. 사망, 34m 이탈, 0.7초 넘는 시야 차단 때 해제한다.
- 회전 상한 3.2rad/s, 보간·작은 각도 무시·1.1m 근접 회전 제한으로 군중/접촉 시 흔들림을 줄인다. 하나의 표식 메시만 재사용하고 평상시에는 선택한 한 개체만 검증한다.
- 락온 중 세 시점 모두 전진·후진·측면 이동한다. 가까운 시점의 카메라는 캐릭터 방향과 일치하고 3인칭 거리는 목표 거리에 맞춰 제한적으로 조정한다. 항공은 두 개체 쪽으로 초점을 조금 옮긴다.
- 해제하면 기존 연속 선회로 돌아간다. 자유 이동의 최대 100°/s·입력량 비례·가감속 규칙은 유지한다. 공격 준비/접촉/회복 동안 확정된 검격 방향을 목표 이동이 바꾸지 않는다.

### 공격 연결과 판정

- 대시의 마지막 0.14초에 받은 직접 입력 하나를 0.24초 동안 예약한다. 대시가 끝나면 한 번만 실행하며, 대검 강공격을 놓은 입력도 보존한다. 입력이 없으면 공격하지 않는다.
- 일반/쌍검/대검 입력 예약 구간은 0.20/0.16/0.24초, 콤보 연결 여유는 0.80/0.65/1.05초다. 실제 타격 직전 0.04초부터 마지막 타격 뒤 0.08초까지 대시·패링 취소를 막고, 그 밖의 준비/회복 구간에는 취소를 허용한다. 시전 취소는 기존 기술 쿨타임을 돌려주지 않는다.
- 검 부채꼴과 방향은 행동 시작 때 확정한 데이터에서 계산한다. 적 크기에 따른 피격 반경과 몸에 밀착한 적을 고려한다. 검/검기/마법은 벽·기둥·언덕에 가려진 적을 때리지 않는다.
- 얇은 벽도 선분 교차로 검사한다. 검기와 적 탄환은 이동 구간의 첫 벽에서 멈추며, 화염구는 실제 목표까지의 수명과 구간 충돌을 사용한다. 설치 마법과 조준 예고는 같은 벽 앞 위치로 제한한다. 시전 중 이동해도 화염구는 표시했던 목표를 향한다.
- 실제 검날의 진행 방향을 따르는 에너지 궤적의 바깥 끝을 확정된 공격 사거리에 맞춘다. 강화/강공격으로 연장된 범위는 에너지 날로 표현한다. 지면 판정 예고와 피해도 같은 공격 프로필을 사용한다.

### 층 목표와 지역 분기

1층과 최종 10층은 기존 90초 보스·120초 생존 흐름을 유지한다. 2–9층과 심연은 런/지역/층으로 다음 여섯 목표 중 하나를 배정한다. 지역 선택 카드에 목표·조건·보상을 미리 표시한다.

| 목표 | 실제 완료 조건 | 확정 추가 골드 |
| --- | --- | --- |
| 정예 사냥 | 표식이 있는 정예 2마리 처치 | 기본 골드 ×8 |
| 결계 방어 | C로 시작, 실제 습격 공격을 저지하며 28초 방어 | ×10 |
| 균열 돌파 | 분출 예고가 있는 표식 3개를 순서대로 통과 | ×10 |
| 봉인 해제 | 각 수호자를 처치하고 장치 3개에서 C | ×9 |
| 추적 사냥 | 표식을 따라 강화 돌격수 처치 | ×9 |
| 소환 의식 | C로 시작, 장치 12m 안에서 일반 적 5마리 처치 | ×8 |

추가 골드는 현재 층 기본 골드에 기존 지역·경로·계약·유물 배율을 적용해 한 번만 지급한다. 목표 완료와 최소 20초 경과 후 보스를 소환하고, 목표와 보스 처치를 모두 마쳐야 기존 경로/지역 선택으로 이어진다. 강제 능력치 상승은 없다. 방어 장치는 파괴되면 C로 수리해 다시 도전할 수 있다. 비밀 공간·훈련의 처치는 목표에 포함하지 않는다. 목표 표식은 최대 3개, 방어 습격자는 최대 3마리이며 전체 160마리 상한을 지킨다.

숨겨진 진화/유물 조합은 그대로 유지한다. 연계의 별도 표시·B 설명·피해 통계와 런 내 발동 횟수를 제공한다. 폭발은 `link` 피해로 처리해 검/화염 조건을 다시 생성하지 않는다. 마법 보너스는 성공적으로 생성된 투사체/장판에만 저장하며 다른 시전에 새지 않는다.

### 보스와 고난도 전투

보스 선택은 거리·가장자리·현재 위험 지대·플레이어의 이미 드러난 회복 자세를 사용하며 입력 키를 읽지 않는다. 포격은 노출된 원거리 플레이어를 압박하고, 역병은 위험 지대가 많거나 가장자리일 때 독침을 고려하며, 사신은 가장자리에서 중앙 쪽 착지 지점을 예고한다. 3페이즈와 최근 패턴에 따른 변화도 유지한다.

지연 탄막 연계 뒤에도 일반 1.2초/3페이즈 0.9초 회복을 확보한다. 연계 진행 중에는 회복 피해 보너스를 주지 않고, 실제 회복에는 기존 +20%를 적용한다. 독 장판 중심 간격을 6.8m로 벌려 반경 3.1m 사이 탈출 통로를 만든다. 패링 차단 시 예약 공격을 정리하고, 지면 위험은 기존의 방어 불가 규칙을 유지한다. 보스 바 아래에 연계/회복과 반격 기회를 표시한다.

일반 적 협공은 초반 2명·후반 3명·심연 4명, 평시 인원 목표 6–15·위험/심연 25·절대 상한 160을 유지한다. 적 체력·기본 피해, 플레이어의 선택 성장·영구 강화 가격, 회복과 마법 쿨타임을 일괄 상향/하향하지 않았다. 강한 광역 기술은 다수에게 사용할 때 보상이 크다.

### 야영지 실전 훈련

기본 콤보·강공격/차징·마법·대시·패링·몬스터·만난 보스의 7종을 제공한다. 세 무기와 마법 1/3/5단계(진화 포함)를 선택한다. 더미는 타격/마지막 피해/DPS를 표시하고, 몬스터와 보스는 실제 전투 행동을 사용한다. 분열체의 사망 분열도 한 세대만 재현한다.

전용 평면 연습장에서 모험의 원래 전투 객체·상태·대기시간·통계·장비를 보관하고 임시 소유자를 사용한다. 훈련 사망은 제자리 재개이며 모험의 보상·이야기·기록·정산을 호출하지 않는다. 초기화/종목 변경/나가기가 실제 동작한다. 종료하면 원래 객체와 대기시간이 복원된다. 일반/숨겨진 보스의 조우 기록을 추가하되 이전 처치 기록도 연습 자격으로 인정한다. 지갑·영구 강화 저장 키를 바꾸지 않는다.

## 밸런스 측정과 남은 제한

[14개 실전 시뮬레이션 결과](tactics/balance-scenarios.json)는 실제 피해·대기시간·AI·새 취소 제한을 사용한다. 1/5/10층 영구 강화 0/5/12단계와 명시한 레벨업 카드 빌드로 일반/정예/보스/8마리 혼합 전투를 실행했다. 스크립트가 조준·이동·공개된 예고에 반응하며 무적, 플레이어 체력 추가, 적 체력 감소는 사용하지 않았다.

- 혼합 전투는 1/5/10층 각각 2.66/8.26/3.36초에 처치했으며 남은 체력은 약 100%/84%/80%다. 마법 진화와 선택한 광역 빌드가 큰 보상을 주는지 확인하는 격리 전투다.
- 5층 보스는 38.42초에 체력 약 33%를 남기고 처치했다. 같은 스크립트의 1층/10층 보스는 마지막 페이즈에서 각각 보스 체력 약 6%/21%를 남기고 패배했다. 이 수치를 사람의 승률로 해석하지 않는다.
- 20/40층 심연은 10층의 고정 빌드를 그대로 사용하면 11.28/6.88초에 패배했다. 기존 심연 성장과 교대 제약·협공 상한은 유지했으며, 이 결과로 장기 심연이 균형 잡혔다고 주장하지 않는다. 실제 유물·장비·직업 빌드와 누적 자원 소모를 포함한 장기 플레이 조정은 계속 필요하다.

자동 검증에서 확인한 기능 오류는 남기지 않는다. 실제 iPad/Safari와 저사양 기기의 장시간 GPU 프레임·조작감, 다양한 사람의 빌드 선택과 전체 런 완주 난이도는 이번 Chromium/SwiftShader 검사로 확정할 수 없다. 드로 콜·픽셀·메모리 검사는 실제 모바일 FPS와 구분한다.
