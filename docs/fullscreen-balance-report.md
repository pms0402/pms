# VOIDRUN v0.25.0

## 수정

- `fullscreen.js`, `main.js`, `style.css`: CSS 게임 화면 채우기를 브라우저 Fullscreen API와 분리. 최초 진입부터 화면 채우기, 설정/사운드 버튼 재배치, F10 전환. 네이티브 종료/오류가 CSS 레이아웃을 축소하지 않으며 중복 요청 방지. 네이티브 전체화면은 설정의 명시적 버튼으로만 요청.
- `render-budget.js`, `game.js`: 60–240Hz 콜백에서 전투 60FPS 상한. 메뉴 30FPS, 비전투 선택/일시정지 10FPS. 게임 시뮬레이션은 건너뛴 콜백의 경과 시간을 누적해 처리. 기존 프레임당 최대 시간 제한 유지.
- 고화질 픽셀 예산 PC 300만/터치 180만. 지속 부하에서 배율 0.72까지 점진 조절, 회복 시 복원. 부하가 높으면 그림자를 격 프레임 갱신. 기존 모델, 재질, 그림자 해상도, 지역 구조와 인스턴싱 유지. 설정에서 자동 조절 해제 가능.
- `game.js`: 자석 범위 밖 비활성 전리품과 투사체 궤적에서 먼 적의 벽 검사 제거. 가까운 대상은 기존 높이/벽 검사를 그대로 수행.
- `combat-balance.js`, `balance.js`, `progression.js`, `equipment.js`, `content.js`, `magic.js`, `abyss.js`, `expansion-ui.js`: 작은 선형 성장. 구매 단계/비용/골드/해금/저장 키 유지. 이전 구매 단계는 보존하되 전투 효과는 새 값 적용. 골드 증가와 상자·장비 보상 흐름 유지.
- `boss-combat.js`, `bosses.js`, `boss-phases.js`, `hidden-bosses.js`, `boss-arena.js`, `boss-arena-layout.js`, `parry.js`, `tactical-ui.js`: 횟수가 제한된 연계와 명확한 종료 빈틈, 전환 보호, 거리 기반 돌진, 겹치는 회전 탄막에도 존재하는 공통 틈, 경고 중 조기 빈틈 표시 방지. 히든 보스의 접근/추가 사격/안전지대 개선. 패링은 진행 중 연계를 취소. 소환 동시 상한과 누적 보상 상한 분리.

## 검증

- 단위 테스트 **304/304 통과**. 선형 성장·저장 불변성·연계 상한·페이즈 보호·전체화면 요청·60~240Hz 스케줄링 포함.
- 신규 보스 통합 검사: 일반 6종 + 히든 3종 모두 실제 Game 피해 처리로 방어/빈틈 배율, 2·3페이즈 전환 보호와 해제, 처치·승리 연결 통과.
- 신규 PC/모바일 전체화면 검사: 최초 화면 채우기(네이티브 요청 0회), 설정·사운드 버튼 접근, 메뉴 일시정지/복귀, 명시적 네이티브 요청 1회와 종료 후 화면 유지, 스크롤 없음 통과.
- 1440×960 / DPR 2 / 고화질에서 렌더링 버퍼 **3,538,944 → 2,985,676 픽셀(약 15.6% 감소)**. 390×844 화면은 예산 이하이므로 원래 해상도 유지. 모델·재질·고화질 그림자는 유지. [측정 JSON](fullscreen-balance/viewport-verification.json).
- 브라우저: Chromium + SwiftShader(모바일은 터치 에뮬레이션, 실제 iPad Safari 실기기 검증은 미실시). 스크린샷을 열어 실제 PC 화면의 HUD·지형·캐릭터와 화면 채우기 확인.
- 회귀 검사: 설정·초기화·배속, 마우스 잠금, 터치패드, 패링, 영구 강화·정산, 가격, 10층 능력치 불변, 선택 빌드·상자 보상, 서리, 장비·NPC·무한 심연, 보스 전장 및 정적 배포 경로를 확인했습니다. 기본 브라우저 검사와 10층 성장 검사는 수정된 최종 빌드에서 재통과했으며, 탐험 검사는 PC 구간과 모바일 구간을 나눠 검증했습니다.
- 보스 체력 바는 작은 화면에서 지역 캡션 자리를 사용합니다. PC/터치의 1440×960·1180×820·390×844·844×390에서 상단 조작 버튼 6개와 겹치지 않는 실제 DOM 판정을 통과했습니다.

- 독립 HTML은 단독 페이지와 `allow-scripts`만 있는 불투명 샌드박스에서 시작·이동·일시정지·저장 불가 안내를 검증했습니다. [검증 항목과 빌드 SHA-256](fullscreen-balance/build-verification.json).

## 한계

- 브라우저 자체 전체화면·포인터 잠금 안내문은 웹 게임이 제거할 수 없습니다. 기본 화면 채우기는 네이티브 전체화면을 요청하지 않습니다.
- 자동 조절은 과도한 렌더링 부담을 줄입니다. 실제 하드웨어 FPS는 GPU·해상도에 따라 달라지며 소프트웨어 렌더러의 결과를 실기기 FPS로 보장하지 않습니다.
- 절차적 모델과 애니메이션, 기존 저장 형식은 유지합니다. 낮아진 강화 효과는 의도된 밸런스 변경입니다.
