# 0.15.0 · 적 배치와 이동 동작

세 일반 적이 닫힌 문과 겹쳐 있었다. 기존 배치 검사는 발밑 지형만 확인했고, 바닥 보정 좌표도 일부 배치에 반영하지 않았다. 최종 배치를 바닥·문·통로 벽까지 확인한 뒤 가까운 빈 바닥으로 옮긴다. 처치 기록의 ID는 배치 보정 전에 확정하므로 기존 저장의 몬스터가 다른 종으로 바뀌지 않는다.

주변의 일곱 적만 갱신하던 제한을 없앴다. 같은 공간의 가까운 적은 모두 이동·중력·피격 경직을 갱신한다. 공격을 동시에 시작하는 수는 기존처럼 초반 둘, 이후 셋으로 제한한다. 안전 구역에서는 적이 공격하지 않으며, 제자리로 돌아갈 때에도 문과 바닥의 충돌을 적용한다.

일반 적 21종은 종마다 걷기 또는 비행 24장을 사용한다. 보스 7종도 24장 보행을 사용하며, 에드란의 방패 없는 모습과 아르케인의 망토 없는 모습은 별도 24장이다. 새 이동 시트는 18개이며 실제 사용하는 셀은 720개다. 혼합 시트에서 정체성이 섞인 네 이동 주기는 별도 단일 종 시트로 대체하며, 기각된 행은 렌더링하지 않는다. 무기·신체·옷을 따로 회전하거나 기존 여섯 장을 반복해 프레임 수를 늘린 방식이 아니다. 원본은 이미지 도구로 제작한 시트이며 수작업 상용 픽셀팩이라고 주장하지 않는다.

보행 위상은 실제 이동 거리에 맞추고, 비행은 날갯짓 주기를 따로 둔다. 출발과 정지에 가감속을 적용하고, 멈출 때에는 가까운 발 디딤 자세로 잇는다. 방어 자세가 보행을 덮어 한 장으로 고정되던 순서도 수정했다. 스프라이트별 크기·발바닥·머리 위치는 원본 픽셀을 읽어 등록한다. 검사 스크립트는 PNG를 수정하지 않는다.

전투 예고, 공격 판정, 피격·죽음의 기존 전용 시트는 유지한다. 이번 24장 확장은 **이동 주기**에 적용된다. 모든 공격 패턴을 새 24장으로 그린 것은 아니다. 몬스터의 체력·보상·동전 성장·스토리·체크포인트·저장 형식은 바꾸지 않는다.

검증 명령:

```sh
npm test
npm run test:creatures
npm run test:foes
npm run test:encounters
npm run test:journeys
npm run test:inputs
npm run build
```

`test:creatures`는 실제 Chromium에서 720개 셀의 고유성·투명도·경계를 검사하고, 30개 이동 주기를 실제 AI로 재생한다. 벽에 끼던 `e1011`, `e1057`, `e1072`는 실제 월드 지형에서 키보드 공격으로 처치하여 피격·죽음·처치 기록까지 확인한다. 이미지 검수는 게임과 같은 렌더러로 만든 7개 지역의 프레임 비교 화면과 실제 전투 화면을 사용한다. `test:journeys`는 체크포인트 안전과 여섯 통로, 지역별 전투 밀도와 CPU 시간을 검사한다.

2026-11-24 로컬 검증: 단위·저장 회귀 247개 통과. 21종 실제 AI, 보스 7종의 2페이즈 전투와 안정화·재접속, 여섯 연결 통로 왕복, 7개 지역 밀도, 키보드·마우스·세로/가로 터치 조작, 기존 전투 셀 828개의 출력 검사를 통과했다. 정적 빌드에서도 새 이동 720개 셀과 문제 지점 세 곳의 실제 키보드 처치를 재확인했다. 1440×960 Chromium 밀도 검사에서 프레임의 갱신·렌더링 시간 p95는 3.5~4.5ms였고, 처음 셀 캐시를 만드는 일부 프레임에는 더 긴 멈춤이 남아 있다. 기기별 60fps를 보장하는 수치는 아니다.
