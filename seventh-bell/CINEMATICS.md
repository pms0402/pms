# 0.14.0 · 수호자의 기억

이번 변경의 중심은 보스전 뒤의 이야기다. 현재 메인 이야기는 7장의 카리온과 마지막 종의 선택에서 끝난다. 이후에는 기존 왕국을 계속 탐험할 수 있다.

## 전투 뒤에 이어지는 이야기

기존에는 보스 보상 창과 결말의 텍스트 창만 있었다. 이제 일곱 보스를 처치하거나 안정화하면 바로 전용 기억 장면이 재생된다. 앞쪽 보스에서는 이해하지 못했던 행동의 이유를 보여주고, 뒤쪽 보스로 갈수록 종의 대가와 누나의 행방이 드러난다.

| 보스 | 드러나는 사건 |
| --- | --- |
| 에드란 | 그가 막은 것은 왕국의 입구만이 아니었다. |
| 마리에 | 종에 보관된 목소리와 대신 치러야 했던 대가 |
| 브라그 | 불 앞에서도 떠는 사람들, 스스로 잠근 밸브 |
| 레오넬 | 아직 일어나지 않은 삶이 지워지는 기록 |
| 아르케인 | 왕국을 살린 ‘한 번만 더’가 87년이 된 사연 |
| 네리스 | 돌아오지 않는 배를 위해 남겨 둔 불빛 |
| 카리온 | 종 안의 목소리와 누나의 재회, 마지막 선택 |

각 장면에는 처치·안정화에 따라 다른 대사 또는 흔적이 들어간다. 4장 이전에 ‘미래를 소모한다’는 결론을 먼저 설명하지 않고, 4장의 기록에서 진실을 드러낸다. 독서대·명부·다음 지역의 단서를 남기되 기존 조사와 진행 조건을 건너뛰게 만들지 않는다.

## 재생과 마지막 종

전용 그림, 인물·단서로 이동하는 카메라, 빛과 먼지, 종과 잔향 소리, 짧은 자막으로 구성했다. 일반 보스 장면은 네 장면 약 20초, 마지막 재회는 여섯 장면으로 구성한다. 자막은 완전히 표시하며 각 장면을 최소 5초 유지한다. Space/Enter·다음 버튼으로 넘기거나 일시정지·건너뛰기를 쓸 수 있다. 모션 감소 설정에서는 카메라 이동과 입자를 멈춘다.

장면 중에는 게임을 멈추고 이동·공격을 받지 않는다. 보상은 보스 승리 때 한 번만 지급하며 장면 재생과 다시 보기로 동전·경험치·깨달음을 추가 지급하지 않는다. 체력과 약병도 채우지 않는다.

마지막 재회 뒤에는 보상 창의 ‘누나의 목소리를 따라간다’를 누르면 실제 캐릭터가 작은 종까지 걸어간다. 위치를 순간이동시키지 않는다. 중간에 ‘직접 걷기’로 취소할 수도 있다. 종에서 선택하면 영원한 오늘·진정한 밤·여명의 잔향 각각의 그림과 결말 연출, 마무리 화면으로 이어진다. 숨은 결말의 기존 조건과 이미 저장된 선택은 유지한다.

수첩 → 수호자의 기억에서 도달한 보스 이야기와 선택한 결말을 다시 볼 수 있다. 아직 쓰러뜨리지 않은 보스의 이야기는 잠겨 있다. 구형 저장에서 이미 결말을 골랐지만 연출을 본 적이 없다면 이어하기 후 해당 결말을 한 번 보여 준다.

## 저장과 아트

저장 키는 `seventh-bell.save.v1`, 스키마는 12다. 1~11 저장의 기존 진행·수치·장비·동전 단련·보급품·기계·통로를 유지하고, 본 기억·재생 대기 중인 보스·본 결말만 추가한다. 보스 장면 도중 다시 접속하면 아직 보지 않은 장면을 재생하고 보상을 중복 지급하지 않는다. 예전 보스 여섯 장면을 한꺼번에 강제로 재생하지 않으며 수첩에서 볼 수 있게 한다.

두 PNG에 원본 그림 10컷을 추가했다. 출처는 `assets/LICENSE.md`에 있다. 컷을 추출해 카메라·빛·자막을 움직이는 일러스트 연출이며, 프레임마다 인물이 연기하는 영상이나 성우 녹음을 제작했다고 주장하지 않는다. 전투 스프라이트와 기존 지형은 그대로 사용한다.

## 확인

- Node 검사 **240개** 통과. 보스별 두 결과의 이야기, 단계별 정보 공개, 그림 구획, 저장 이행, 재생 기록과 보상 불변성을 포함한다.
- Chromium에서 7명 × 2가지 결과의 자동 시작, 일시정지·입력 차단·다음·건너뛰기·다시 보기를 확인했다. 자연 시간에 따른 자동 장면 전환도 확인했다.
- 장면 도중 재접속, 마지막 보스 이후 실제 보행, 세 최종 선택과 결말·마무리 화면, 구형 완료 저장의 결말 재생을 확인했다.
- 390×844와 844×390 터치 화면의 그림·자막·버튼을 캡처하고 가로 넘침과 위치를 확인했다. 실제 iPad Safari 검증은 포함하지 않았다.
- 기존 일곱 보스의 실제 양 페이즈 전투, 세 결말 조건, 정비·이동·저장과 기본 입력 검사도 확인했다.

스크린샷과 결과는 무시되는 `test-results/014-*`에 남는다. 변경 범위는 `seventh-bell/`이며 다른 두 게임의 코드와 저장에는 손대지 않았다.
