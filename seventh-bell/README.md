# 잔향: 일곱 번째 종

**ECHOES OF THE SEVENTH BELL · 0.17.1**

누나의 흔적을 찾아 일곱 종을 조사하는 횡스크롤 액션 RPG다. 0.17.1에서는 연결 통로에 장식으로 놓인 문을 교체하고, 겹친 경계 장치를 하나의 돌벽으로 정리했다. 실제로 쓸 수 있는 출입문만 남기고 카메라가 옆 지역까지 보여주지 않게 했다. 승강기를 놓쳐도 각 층의 고정 호출 장치로 다시 부를 수 있다. 기술 나무에 종격(F)과 검은 사슬(G), 다섯 가지 연계 강화를 추가했다. 기존 기본 공격은 끝나기 전 마지막 0.18초에 새로 누른 입력만 이어치기로 받는다. 공격 모션을 끝까지 재생한 뒤 큰 베기와 내려찍기를 잇는다. 회복과 종 보급 실습도 튜토리얼에 포함한다. 종을 칠 때 약병을 세 병까지 보충하며, R/H와 별도 터치 회복 버튼을 쓴다. 앞선 성당 시각 수정은 입구의 한 전투 구간에 한정한다. 돌·문·발판을 성당 배경과 맞추고, 수도사의 준비·타격·회복 자세와 접촉 효과를 다듬었다. [전후 화면](review-cathedral/index.html)과 [검증 기록](CATHEDRAL_REVIEW.md)에서 같은 입력으로 찍은 장면을 볼 수 있다. 초기 로딩 개선은 [LOADING.md](LOADING.md), 중간보스와 멈춤 대응은 [RUNTIME.md](RUNTIME.md)에 정리했다.

## 실행

상위 저장소에서 의존성을 설치한 뒤 Node.js 24로 실행한다.

```sh
npm ci --no-audit --no-fund
cd seventh-bell
npm run dev                 # http://localhost:4191/
npm test                    # 301개 전투·지형·저장·프레임 복구 검사
npm run test:loading         # 준비 파일·2,793칸/배경 픽셀·재접속 캐시·저장 차단
npm run test:combo           # J/Z·마우스·터치의 늦은 입력·연타·모션 완료·기력 소비
npm run test:passages        # 6통로 왕복·실제 문/승강기 선택·불투명 벽 픽셀·충돌 경계
npm run test:lifts           # 27개 고정 호출·중간층 낙하·재호출·재접속·재탑승
npm run test:abilities       # 기술 나무 구매·실제 속박/피해·재사용 저장·터치 배치
npm run test:healing         # 종 충전·R/H·전용 터치 버튼·키 반복·저장
npm run test:cathedral       # 성당 전후 입력·충돌 경계·접촉 효과·투사체 베기
npm run review:cathedral     # 같은 입력의 일곱 장면 재촬영
npm run test:runtime         # iPad 화면의 이동·터치·메모리·예외 복구·저장
npm run test:minibosses      # 7종 실전 처치·보상·재접속·378개 그림
npm run test:creatures       # 720개 이동 셀·30주기·실제 AI·벽 끼임 재현 지점 처치
npm run test:story           # 14가지 보스 기억·재접속·결말·실제 보행·터치
npm run test:growth          # 8종 정비·무한 단련·모든 검술/Q 파쇄·터치·구형 저장
```

브라우저 검사는 상위 저장소의 Playwright와 `/usr/bin/chromium`을 사용한다. 런타임·중간보스 검사는 `BROWSER_ENGINE=webkit`으로 WebKit에서도 실행할 수 있다. 별도 설치 경로는 `WEBKIT_PATH`로 지정한다. 개발 서버의 기본 포트 4191은 Safari에서도 접근할 수 있다. 4190은 Fetch 금지 포트이므로 사용하지 않는다. `BASE_URL`로 빌드한 정적 사이트도 검사할 수 있다. `test:art`, `test:routes`, `test:inputs`, `test:encounters`, `test:progression`, `test:hazards`, `test:foes`로 나눠 실행할 수도 있다. 스크린샷과 측정 결과는 무시되는 `test-results/`에 저장한다. 이전 버전의 긴 수평 경로 드라이버는 기록으로 남겨 두고, 공개 검사 명령은 개편된 경로 드라이버를 사용한다.

| K / X 길게 누른 뒤 놓기 | 모아 베기 |

너무 일찍 누른 기본 공격 입력은 저장하지 않는다. 공격 동작의 마지막 0.18초에 다시 눌러야 현재 동작이 끝난 뒤 다음 베기로 이어진다. 키를 누르고만 있어도 자동으로 이어지지 않는다. 기력은 실제로 다음 동작을 시작할 때 한 번 소비한다. 도약·회피 취소와 특수 검술의 조작은 유지한다.

터치에서는 화면 아래 이동·동작 버튼과 가까운 장치 안내를 누른다. 공격 버튼 왼쪽의 회복 버튼으로 약을 마실 수 있으며, PC에서는 R 또는 기존 H를 쓴다. 약은 멈춰 서서 마시며 피격 시 끊긴다. 종을 치면 약병 세 병을 채우고 진행을 기록한다. 체력은 약을 마셔 회복한다. 레벨업·정비·빠른 이동은 보급품을 채우지 않는다. 사망 후 재도전에는 체력과 약병 세 병을 돌려준다. 새 게임은 별도 점검기사 튜토리얼로 시작하고, 바로 본편으로 들어갈 수도 있다. 새 연습은 무릎을 다친 설정으로 체력 60%에서 시작한다. 막기를 익히면 기사가 쉬는 동안 회복약을 직접 마시고, 마지막 종에서 세 병으로 보충된 것을 본 뒤 본편으로 나간다. 약을 먼저 마셨다면 그 행동도 인정한다. 약병이 비면 왼쪽 연습 종을 쓸 수 있다. 메뉴에서 다시 연습하면 본편의 체력·약병·장비·위치를 그대로 돌려준다.

## 종의 기술과 승강기

T 또는 성장 메뉴의 기술 나무에서 **종의 기술** 갈래를 고른다. 종격과 검은 사슬은 각각 깨달음 1점으로 익힌다. 종격은 집중 24를 쓰며 주변에 충격파를 내보내고 일반 적 투사체를 부순다. 검은 사슬은 집중 20으로 전방의 일반 적을 묶는다. 보스와 중간보스는 멈추지 않으며, 대신 잠시 받는 피해가 10% 늘어난다. 돌벽 너머에는 닿지 않는다. 두 능력은 공중에서도 사용할 수 있고, 준비 중 피격·회피로 취소되면 집중과 대기시간은 돌아오지 않는다.

위력, 범위와 재사용 시간, 사슬 거리, 속박·취약 지속시간을 강화하고 마지막에는 사슬에 걸린 적에게 종격 피해를 25% 더 줄 수 있다. 일곱 칸을 모두 배우는 데 10점이 든다. 능력 피해는 레벨·집중 정비·단련에 따라 오르며 검 강화에 종속되지 않는다. 배운 뒤에만 화면에 사용 버튼이 나타난다. 터치에서도 각각의 전용 버튼을 쓴다. 집중 소모와 남은 대기시간을 표시하고 재접속으로 대기시간을 지울 수 없도록 저장한다. 사망 후 재도전에서는 다시 사용할 수 있다.

11개 승강기의 양 끝과 성당 중간층을 합쳐 27곳에 고정 호출 장치를 놓았다. 발판이 떠나도 호출기는 그 층에 남는다. 가까이 가서 W/E나 화면 안내를 누르면 해당 층으로 온다. 발판 위에서 다시 작동시켜 타고 이동하며, 이동 중 같은 조작으로 방향을 바꿀 수 있다. 기존 잠금 장치는 먼저 해제해야 한다. 기존 상층 통로와 승강로 사이가 끊겨 있던 곳은 착지용 연결 발판을 보완했다.

## 출입구와 경계 수정

여섯 지역 연결 통로에 출입문 그림을 장식으로 재사용하지 않는다. 광산 수레, 돌벽 장식, 창문, 암벽과 등대가 배경을 채우고 실제 문은 각 구간의 두 출구에만 놓인다. 화면과 상호작용은 현재 지역에 속한 출입구만 취급한다. 종탑의 해안길 복귀 문은 승강기와 호출 장치에서 떨어진 바닥으로 옮겼다. 기존 승강기 위치·장치와 모든 일반 적 ID·배치는 유지한다.

기존 장별 차단문과 보이지 않는 통로 정지면을 중복 생성하지 않고 지역 재질에 맞는 불투명한 벽으로 연결했다. 벽 위쪽도 같은 충돌면으로 막으며, 카메라는 돌벽 바깥의 다른 지역을 비추지 않는다. 지형 타일 아래에도 불투명 바탕을 채워 원본의 투명 부분으로 배경이 비치지 않게 했다. 이전 저장 위치가 새로 정리한 경계 안에 있다면 그 출입구 앞의 바닥으로만 옮긴다. 체력·약병·동전·능력·진행 기록은 바꾸지 않는다. 벽 안에 남은 사망 동전도 같은 출입구 앞에서 회수할 수 있다. 원본 스프라이트와 준비된 그림 파일을 다시 만들거나 추가하지 않았으므로 초기 이미지 다운로드도 늘지 않는다.

## 이번 버전의 구조

- 보스 7명에게 전용 행동 컨트롤러와 총 37개 행동을 연결했다. 체력은 요청한 값으로 정확히 두 배다. 거리·직전 공격·남은 위험 구역·페이즈를 보고 선택하며, 준비 중 고정한 목표를 몰래 따라 바꾸지 않는다.
- 21종 일반 적은 서로 다른 외형·이동·준비·공격·반응 그림과 AI를 쓴다. 종을 든 신도와 수도사를 함께 배치했고, 공명 부유체도 서로 영향을 줄 수 있는 거리에서 만난다.
- 모든 검 공격의 활성 구간과 날아가는 공명 검이 일반 적 투사체를 지운다. 실제 검날의 이동과 투사체의 이동을 연속 검사하고, 검·몸·벽 중 먼저 만난 곳을 처리한다. 보스 특수 공격과 함정은 이 규칙으로 지워지지 않는다.
- 네 반복 계단 구간을 새 외벽·성당 승강로·운반로·책장길로 교체했다. 왕궁 상층 지름길, 항구의 위·아래 경로, 1,302단위 종탑 등반도 연결했다. 승강기와 회전 발판은 실제 충돌면이며 플레이어를 운반한다.
- 책장이 공격을 막고, 지워지는 바닥은 그림과 충돌이 함께 열린다. 바닥 아래에 플레이어가 남아 있으면 복원을 잠시 미룬다. 등대 빛은 엄폐물에 막히고, 임시 발판은 사라지기 전에 점멸한다.

## 아트와 저장

중간보스 전용 그림 378장(7종 × 54장), 기존 보스 그림 450장과 일반 적 그림 378장을 사용한다. 기존 수리공의 24장 검술 시트와 보행은 유지했다. 원본 PNG의 실제 여백을 측정해 각 셀을 자르고, 한 시트 안에서는 같은 배율을 쓴다. 발 기준점과 무기 끝점은 등록 데이터로 보정한다. 안개는 인물 뒤에 그리며, 순간이동·분신 등 지정된 연출을 제외한 살아 있는 보스는 불투명하다. 생성 원본의 출처는 [assets/LICENSE.md](assets/LICENSE.md)에 있다. 실행용 파생 파일은 `assets/packed/`에 있으며, PNG 원본을 수정하지 않는 무손실 인코딩이다. 원본·추출 코드가 바뀌면 개발 서버를 켜고 `npm run art:pack`으로 다시 만든다. 이 명령은 Chromium과 FFmpeg의 libwebp 인코더를 사용한다. 빌드에서 원본과 준비 파일의 해시가 어긋나면 실패하므로 오래된 그림을 게시하지 않는다. 원본 여백을 다시 등록할 때는 Pillow가 있는 환경에서 `python tools/measure-atlases.py`를 실행한 뒤, 개발 서버를 켜고 `node tools/register-bosses.mjs`를 실행한다. 두 도구는 PNG를 수정하지 않고 등록 데이터만 기록한다.

저장 키는 `seventh-bell.save.v1`, 스키마는 12이다. 버전 1~11의 보스 결과·능력·장비·수첩·동전·체력·약병을 보존한다. 새 지름길과 기계의 위치·위상·목표 높이도 저장한다. 지하 묘지의 기존 승강기도 같은 기계 기록에 포함했다. 선택 필드 `abilityReady`는 저장된 플레이 시간을 기준으로 두 능력의 다음 사용 시각을 보존한다. 이 필드가 없는 기존 저장의 능력과 점수는 그대로 남는다. 같은 스키마의 선택 필드 `minibosses`에 중간보스 처치 기록을 더하며, 이 필드가 없는 기존 저장은 빈 기록으로 읽는다. 이전 저장 위치가 새 벽 안에 있는 경우 위치만 마지막 종 앞으로 옮기고 안내한다. 기존에 통과한 구역과 완료한 장의 지름길은 다시 막지 않는다. 튜토리얼의 선택 필드 `healed`와 `refilled`는 실제 회복·보급 실습을 기록한다. 이 필드가 없는 진행 중인 구형 연습은 기존 단계와 체력·보급품을 그대로 유지한다.

Canvas 2D와 Web Audio로 실행하며 외부 런타임이나 CDN을 요구하지 않는다. VOIDRUN·ELDERMERE의 코드와 저장은 공유하지 않는다. 빌드 시 HTML·모듈·이미지에 같은 버전/커밋 식별자를 붙인다. `verify:live`는 공개 버전, 커밋, 엔트리 해시와 모든 실행 파일의 응답을 검사한다.

## 확인 범위

지형과 보스 검사는 일반 적·함정을 분리한 독립 장면에서 실제 입력으로 진행한다. 보스전 중 체력·피해량·재화·위치를 바꾸지 않는다. 일반 적, 함정, 성장, 결말과 저장은 별도 자동 검사로 확인한다. WebKit에서도 iPad 크기의 터치 조작·프레임 복구·재접속과 7종 중간보스 실전 처치를 확인했다. 모든 적과 함정을 켠 상태의 1~7장 장시간 수동 완주나 실제 iPhone·iPad 기기의 Safari 성능을 확인했다는 뜻은 아니다. 새 능력은 기존 시전 스프라이트와 코드로 그린 픽셀 효과를 사용하며 새 전용 스프라이트시트를 추가한 것은 아니다. 생성 스프라이트는 전용 원본이지만, 짧은 준비·타격 프레임 사이의 관절 연결에는 추가 수작업 여지가 있다.
