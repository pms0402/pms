# 잔향: 일곱 번째 종

**ECHOES OF THE SEVENTH BELL · 0.9.2**

이름 없는 종 수리공이 누나를 찾아 왕국으로 돌아온다. 성벽·대성당·제철도시·서고·왕궁이 이어지는 **제1~5장**과 마지막 선택을 플레이할 수 있다. VOIDRUN·ELDERMERE와 코드, 에셋, 저장이 분리된 Canvas 2D/Web Audio 게임이다. 외부 런타임이나 CDN은 없다.

## 실행과 검사

Node.js 24에서:

```sh
cd seventh-bell
npm run dev                  # http://localhost:4190/
npm test
npm run test:reset            # 초기화·실제 새로고침·취소·저장 실패·터치
npm run test:frames           # 잔상 없이 베기마다 실제 몸 그림 24장·60Hz 재생 확인
npm run test:motion           # 위 프레임 검사 + 판정·잔상·좌우·공중·터치
npm run test:techniques       # 대공·대시 찌르기·낙하·모으기·반격·터치
npm run test:tutorial         # 새 게임·실제 조작 증명·별도 연습·저장·터치
npm run test:browser          # 기본 전투·첫 보스·터치
npm run test:interaction      # 화면·말풍선·부탁·제한 회복
npm run test:workshops        # 획득한 동전으로 정비·종길 이동
npm run test:palace           # 1~5장 경로와 다섯 보스, 마지막 선택
npm run test:action           # 위 경로 + 함정·새 아트·모바일 기술 나무
npm run build
```

브라우저 검사는 상위 저장소의 Playwright와 `/usr/bin/chromium`을 쓴다. `BASE_URL`로 빌드한 정적 서버도 검사한다. `dist/`를 HTTP 정적 호스팅에 올린다. HTML·모듈·이미지에 같은 버전/커밋 식별자를 붙이고, `verify:live`는 공개 버전과 엔트리 해시, 모든 코드·아트 파일을 확인한다.

## 성벽에 들어가기 전

새 게임의 기본 시작은 **종 수리장의 점검**이다. 1,950단위의 별도 무대에서 이동·실제 발판 점프를 익히고, 전용 24프레임을 쓰는 미니보스 **낡은 점검기사**를 상대한다. 검이 닿는 두 번 이어치기, 실제 공격 회피, 정면 막기/패링, 강공격 적중, 공명 검 적중을 확인한 뒤 마지막 겨루기로 이어진다. 키를 누르기만 해서는 적중·방어 단계가 완료되지 않는다. 해당 단계에 필요한 조작만 작은 안내창에 보여 주며 휴대폰에서는 터치 버튼 이름으로 바뀐다. 본편 보스의 패턴 설명은 추가하지 않는다.

점검기사는 느린 준비 자세와 긴 회수 시간을 가진 두 동작을 쓴다. 칼의 그림과 같은 등록점으로 무기 선분을 판정한다. 점검용 공격은 체력을 1 아래로 내리지 않는다. 약병은 여전히 세 개뿐이고, 점검을 마치거나 건너뛴다고 체력·약병이 채워지지 않는다. 연습 적은 돈·경험치·성장 점수를 주지 않는다. 완료 후 오른쪽 종을 누르면 누나의 편지와 성벽의 첫 장이 시작된다.

진행 단계·이어치기 확인·기사 상태·현재 체력·약병은 저장한다. 첫 화면의 **바로 성벽으로** 또는 연습 안내의 **건너뛰기**도 사용할 수 있다. 이전 버전의 진행 기록은 그대로 본편에서 이어진다. 메뉴의 **조작 연습**은 별도의 기본 장비 인물로 진행하며 원래 세계·캐릭터·위치·체력·집중·약병·기술 재사용 시간·재화를 보관했다가 돌려준다. 연습 중 새로고침해도 원래 본편 저장으로 돌아간다. 보스전이나 적이 가까운 상태에서는 들어갈 수 없다.

## 이어지는 다섯 지역

| 장 | 실제 장소와 장치 | 수호자와 진행 능력 |
| --- | --- | --- |
| 1 · 잊힌 성벽 | 병영, 순례교, 묘지, 성문 레버, 승강기, 엘마의 부탁 | 에드란 · 두 번째 도약과 잔향 감지 |
| 2 · 침묵의 대성당 | 순례자의 회랑, 성가대석, 종줄, 찢어진 악보 | 마리에 · 목소리 발판 |
| 3 · 불 꺼진 제철도시 | 운반로, 화로실 밸브, 작업반 장부, 도가니 다락 | 브라그 · 봉인을 깨는 강공격 |
| 4 · 뒤집힌 서고 | 책들의 미로, 색인 장치와 책 다리, 연료 장부, 정정 기록 | 레오넬 · 기억의 발판 |
| 5 · 왕관 없는 궁전 | 왕궁 지하 권양기, 서쪽 날개, 상층 명령서, 아래 종축, 옥좌 | 아르케인 3세 · 마지막 종의 선택 |

월드 폭은 15,400에서 **30,600 세계 단위**가 됐다. 기존 1~4장에 8,200단위를 추가하고 왕궁 7,000단위를 연결했다. 기존 도약 간격을 늘리지 않고 평평한 구간 사이에 새 장소를 끼웠다. 회랑마다 도약 구간·높은 보상 길·연결 부품·적·함정이 있다. 새 체크포인트와 정비대도 함께 둔다.

가시에는 닫힘·경고·돌출·회수 상태가 있다. 진자는 실제로 흔들리는 종 머리에서, 압착기는 내려오는 철틀에서 피해를 준다. 벽 쇠뇌는 점멸 후 유한 거리의 화살을 쏜다. 경고만으로 피해를 주지 않으며 무적 회피와 점프로 통과할 수 있다. 기계 함정은 검으로 패링하지 않는다.

서고 뒤 입탑 기록을 읽어야 왕궁에 들어간다. 왕궁의 두 장치를 움직여야 옥좌에 닿는다. 보스는 두 페이즈, 고정한 공격 방향과 주문 위치, 준비·공격·회수 시간을 가진다. 공격명·공략 문구·카운트다운·반격 지시는 화면에 띄우지 않는다. 준비 자세와 빛·소리로 관찰한다. 보스가 싸우는 동안 바깥 일반 적은 멈춘다.

각 수호자의 기록을 찾았다면 약해진 종을 안정시킬 수 있다. 싸워 쓰러뜨리는 선택도 진행 파편을 준다. 보상은 각자 한 번만 지급한다. 최종 종에서는 유지/정지를 선택한다. 다섯 종 안정화, 엘마의 부탁, 연료 장부·누나의 기록, 네 회랑의 연결 부품을 갖췄다면 빛을 나누는 세 번째 선택이 열린다. 선택과 화면의 변화는 저장하며 결말을 반복 교체해 보상을 얻지 않는다. 자세한 문장은 [STORY.md](STORY.md)에 있다.

## 모션과 검의 판정

캐릭터의 기존 키와 성인 체형을 유지하고, 몸을 화면 안쪽으로 돌리던 자세를 옆모습으로 바꿨다. 기본기는 **큰 사선 베기 → 강한 양손 내려찍기**다. 어깨의 기울기, 무릎 굽힘과 발 디딤으로 힘을 싣고 옷자락이 뒤따라온다. 기본 2연타·대공기·강공격·공중 베기·낙하 공격·찌르기에 전용 6×4 시트 일곱 장, 총 168개의 실제 몸 그림을 사용한다. 각각 24장이다. 준비 4장 → 타격 2장 → 복귀 18장으로, 칼이 지나가는 순간은 60Hz 기준 두 프레임이다. 방해받지 않은 일곱 종류 모두 24단계가 재생된다. 기본 콤보에서는 올려베기를 빼고 첫 베기에서 내려찍기로 바로 잇는다. 내려찍기는 기본 피해 44(이전 33), 넉백 230(이전 160), 집중 소모 15다. 준비 0.2초 후 빠르게 내려치며, 낮은 마무리 그림에서 0.0825초(보스 0.099초) 멈춘다. 일반 적의 경직도 0.48초로 늘리고, 낮은 충격음과 바닥 먼지를 더했다. 이어치기와 회피·점프 캔슬은 복귀 동작을 중단하므로 일부 복귀 그림을 건너뛴다. 회복약 동작은 캔슬할 수 없다.

회피 중 일반 공격은 긴 **찌르기**, ↑+공격은 일반 적을 띄우는 **대공기**, 공중 ↓+공격은 **낙하 공격**이다. 낙하는 실제 바닥에 닿아야 끝나며 원거리 충격파를 만들지 않는다. 대공기는 보스·날짐승·점검기사를 띄우지 않는다. K/X를 누르고 있다 떼면 강공격이 나가고, 0.5초 이상 모으면 피해가 1.65배가 된다. 집중은 놓는 순간 한 번만 쓴다. 모으는 중 이동·공격 무적이나 회복은 없고, 점프·회피·피격·창 전환으로 취소하면 뒤늦은 키 해제에서 공격이 나가지 않는다. 정면 패링 성공 후 0.8초 안에 공격하면 집중 16을 쓰는 **반격 베기**로 파고든다. 찌르기·반격의 이동도 벽과 충돌한다. 찌르기는 전용 24장 시트를 쓴다. 0.14초 동안 팔꿈치를 뒤로 빼고 손을 허리 뒤로 당겨 뒷다리에 체중을 실었다가, 앞발을 디디며 팔과 검을 곧게 뻗는다. 반격은 기본 베기, 대공기는 올려베기의 몸 그림을 사용한다.
각 그림의 주먹과 발을 따로 등록하고, 같은 등록점에 일정한 길이 48의 검을 붙인다. 손잡이부터 칼끝까지의 좌표와 좌우 반전을 **그림과 공격 판정이 함께 사용**한다. 검 길이는 30에서 48로 60% 늘렸다. 두 프레임의 칼끝을 직선으로 잇던 판정을 회전하는 칼날의 경로로 바꿔 큰 베기의 바깥쪽도 맞는다. 프레임 사이의 칼날 경로도 검사하며 한 동작에서 한 적은 한 번만 맞는다. 준비·복귀와 잔상에는 공격 판정이 없다. 바닥에 선 채 손이 낮아지는 마무리 자세에서는 검끝이 지면을 뚫지 않도록 같은 등록 각도를 조정한다. 판정에는 2픽셀의 칼날 두께 여유가 있다. 제동·약병·공명은 기존 전용 동작을 사용한다.

칼날이 실제로 지나간 위치를 짧은 빛의 띠와 옅은 몸체 잔상으로 남긴다. 검 위치 사이를 하나의 큰 삼각형으로 채우지 않고, 회전 각도를 최대 2.5도 간격으로 나눠 둥근 가장자리로 연결한다. 잔상과 공격 판정은 같은 고정 길이의 칼날 회전 샘플을 쓴다. 준비 자세의 마지막 위치는 공격이 시작된 뒤에만 궤적에 포함하며, 준비 중에는 적을 때리지 않는다. 잔상은 0.14초 안에 사라지고 추가 피해를 주지 않는다. 타격 정지 중에도 사라지며, 회피·막기·피격·사망·이동 시 이전 공격의 잔상을 비운다. 바닥에서 시작하거나 종길로 이동했을 때는 실제 발판을 검사해 첫 베기가 공중 모션으로 시작하지 않게 했다.

지상 공격은 준비할 때 3~4만큼 뒤로 체중을 싣고, 타격에 맞춰 9·11·16·14만큼 앞으로 디딘다. 움직임은 지형 충돌을 검사하므로 벽을 통과하지 않는다. 검을 베는 소리는 활성 구간에서 한 번 재생하며, 강공격과 마무리에는 더 무거운 소리와 타격 정지·화면 흔들림을 적용한다. 연습기사는 플레이어가 너무 붙으면 한 걸음 물러나 제대로 검이 닿는 거리에서 공격한다. 방향 전환은 실제 속도와 제동 자세를 따라가고, 공중 공격은 다리를 접은 전용 그림을 쓴다. 타격 정지는 일반 0.05초, 강한 일격·보스 타격은 최대 0.099초다. 패링에는 금속음·짧은 화면 섬광과 0.09초 정지를 준다. Q는 사거리 145의 실제 움직이는 공명 검을 내보내며 벽에서 사라진다. 검이 없는 넓은 공간을 즉시 타격하지 않는다. 점프 버퍼 0.13초·코요테 타임 0.11초, 가변 도약, 회피 무적, 정면 막기·패링은 유지했다.

## 기술 나무와 정비

**T 또는 성장 버튼**으로 기술 나무를 연다. 검술·생존·기동·잔향 각 5개, 총 20개 기술이다. 선행 기술과 깨달음 비용을 검사하며 두 갈래를 함께 배워야 열리는 기술도 있다. 검 피해·강공격 속도·패링 반격·체력·막기 비용·피격 경직·집중·회피 비용·공중 제어·약 마시기·공명 피해/관통/재사용·발판 지속에 실제로 적용한다. 레벨업과 보스·숨은 기록에서 점수를 얻는다. 학습으로 현재 체력이나 집중을 채우지 않는다. 모바일에서는 갈래 탭으로 고른다.

15개 체크포인트와 엘마의 작업대 근처에서 같은 장비를 정비할 수 있다. 동전 사용처는 다음과 같다.

| 정비 | 비용과 효과 |
| --- | --- |
| 종강검 | 35/75/115/155/195/235. 단계당 피해 +4, 최대 +6. +3 이후는 진행 파편 필요 |
| 방어구 | 90/150/230. 단계당 받는 피해 2 감소 |
| 손잡이 | 75/125. 단계당 공격 집중 소모 8% 감소 |
| 매듭 부적 | 35. 다음 사망 동전 손실을 50%에서 20%로 줄이고 소모 |
| 종길 이동 | 12. 발견하고 기록한 종 사이 이동. 보스전·가까운 적·미발견 종은 불가 |

이동은 체력·집중·포션·재사용 시간·적을 초기화하지 않는다. 잔액 부족·이미 보유·진행 잠금·먼 거리 구매에는 차감이 없다. 포션 판매는 없다.

## 회복과 저장

시작과 사망 후 재도전 때 **약병 3개**, 한 병은 최대 체력의 **40%**다. 멈춰 서서 마시며 기본 0.8초 동작 중 0.5초에 회복한다. 적용 전 맞으면 약만 잃는다. 기술로 마시는 시간만 줄일 수 있다. 종·레벨업·학습·보물·퀘스트는 회복시키지 않는다.

시작 화면의 **새로 시작**에서 확인하면 이 게임의 기록만 지우고 종 수리장부터 시작한다. 기록을 지운 게임 인스턴스는 종료 시 자동 저장과 수동 저장을 중단해 새로고침 중 이전 진행이 돌아오지 않게 한다. 취소하면 기존 기록이 남으며, 브라우저가 삭제를 막으면 안내를 띄우고 새로고침하지 않는다. 첫 플레이 후 메뉴의 **처음 화면**으로 돌아가도 새로 시작 버튼이 나타난다.

저장 키는 `seventh-bell.save.v1`, 스키마는 7이다. 버전 1~6 저장의 체력·포션·동전·장비·기술·보물·보스 결말을 보존한다. 0.5 이하의 위치와 떨어뜨린 동전 위치는 확장 지도에서 대응하는 곳으로 한 번 옮긴다. 0.6의 위치는 다시 옮기지 않는다. 기존 시작 기록은 점검 완료로 이전해 본편으로 이어진다. 사망은 체크포인트 재도전과 일반 적 초기화를 함께 기록한다. 다른 게임 저장에는 접근하지 않는다.

## 조작

전체 화면을 게임이 채운다. 터치 이동·도약·일반/강공격·회피·막기·공명·잔향·약병도 있다. 올려·찍기 전용 버튼과 길게 누르는 강타도 지원한다. 작은 세로 화면은 3×3, 가로 화면은 5열로 동작 버튼을 놓는다. 1440×960에서는 720×480을 2배 출력하며 보간을 끈다. 엘마의 말풍선은 가까이 가면 나타나고 멀어지면 사라진다. 마지막 말 뒤 수락/납품을 고르며 실제 납을 가져와야 보상받는다.

## 아트와 검증 한계

생성한 원본 PNG 31장을 사용한다. 전용 베기·찌르기 시트 일곱 장의 실제 몸 동작 168셀, 수리공 기본 64셀과 이전 동작 시트, 대기용 몸체·별도 검 이미지, 일반 적 48프레임, 다섯 보스 각 24프레임과 점검기사 24프레임, 다섯 지역의 배경과 지형·시설·함정 아틀라스다. 출처는 [assets/LICENSE.md](assets/LICENSE.md)에 기록했다. 사진이나 기존 게임의 스프라이트를 가져오지 않았다. 그리드 추출·등록점·알파 정리·최근접 출력으로 실제 게임에 연결했다. 사람이 모든 픽셀과 중간 동작을 다듬은 상용 팩이라고 주장하지 않는다. 일부 관절 연결과 중간 프레임은 더 다듬을 여지가 있다. 소리는 오리지널 Web Audio 합성과 편곡이다.

101개 단위 검사는 이동·전투·저장·경제의 회귀와 새 검 선분·기술 선행 조건·효과·함정·왕궁 장치·결말의 일회 저장을 다룬다. 이전 세 타격 튜토리얼에서 일부만 완료한 저장도 새 2연타로 마칠 수 있다. 초기화 이후 저장 차단과 실패 처리, 새 검의 고정 길이·서로 다른 베기 방향·뒤로 힘을 모으는 이동과 벽 충돌·타격음 시점·24단계 선택·60Hz 재생·이어치기 자세·잔상 수명·피해 중복 방지·공중/지상 전환도 검사한다. `test:techniques`는 실제 키보드·마우스·터치 경로의 대공과 점프 캔슬, 회피 찌르기, 낙하와 실제 착지, 길게 누른 모아 베기, 창 전환 취소, 실제 일반 적의 공격을 패링한 뒤 반격, 모바일 버튼 겹침을 검사한다. 찌르기 직전의 팔꿈치·손 당김과 대시 후 전용 시트 재생을 키보드·터치로 확인하고, 80단위 앞의 적에게는 맞고 115단위의 적이나 벽 뒤에는 맞지 않는 큰 베기도 검사한다. `test:reset`은 실제 새로고침과 페이지 종료 자동 저장, 삭제 취소·실패, 새 튜토리얼 저장, 다른 게임 기록 보존, 첫 플레이 후 모바일 초기화를 검사한다. `test:frames`는 잔상·파티클·피격 효과를 제외한 실제 렌더러에서 각 베기의 몸 이미지 24종·몸 실루엣 24종·완성 그림 24종을 확인하고, 60Hz 실행에서도 24단계를 확인한다. 단계별 그림은 `test-results/092-*-24-poses.png`에 남긴다. `test:motion`은 이 프레임 검사 후 실제 렌더러에서 두 번의 기본 베기와 정확한 한 번씩의 피해, 둥근 잔상의 중간 가장자리, 좌클릭 방향·공중 베기·강공격·모바일 터치의 잔상을 캡처한다. `test:tutorial`은 새 게임의 기본 진입, 실제 착지와 키보드 이어치기, 입력으로 증명하는 회피·막기·강공격·공명, 중간 저장과 완료, 0.6 저장의 별도 연습과 복귀/새로고침, 터치 이동·점프·이어치기를 확인한다. 실제 Chromium 본편 경로 검사는 처음부터 획득한 저장으로 다섯 보스와 필수 장치·기록·왕궁의 마지막 선택까지 입력 드라이버로 진행한다. 해당 경로에서는 **일반 적과 함정만 제외해 지형·보스 전투를 분리**한다. 일반 적·투사체·함정·새 이미지 108셀·모바일 기술 학습과 화면은 별도 브라우저 검사로 확인한다. 함정 검사는 시작 위치를 정하는 독립 테스트 장면을 쓰며 점프 통과는 실제 이동 입력으로 검사한다. 전체 적과 함정이 있는 상태의 장시간 수동 완주, 모든 실기기 성능, 숨은 결말의 처음부터 끝까지의 수동 완주를 검증했다고 주장하지 않는다. 스크린샷은 무시되는 `test-results/`에 남긴다.
