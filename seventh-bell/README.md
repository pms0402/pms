# 잔향: 일곱 번째 종

**ECHOES OF THE SEVENTH BELL · 0.5.0**

이름 없는 종 수리공이 누나의 편지를 들고 왕국으로 돌아온다. 잊힌 성벽, 침묵의 대성당, 불 꺼진 제철도시, 뒤집힌 서고가 하나의 횡스크롤 월드로 이어진다. 에드란·마리에·브라그·레오넬을 만나는 **제1~4장**을 플레이할 수 있다.

이 폴더는 독립된 게임이다. VOIDRUN과 ELDERMERE의 코드·에셋·저장을 사용하지 않는다. Canvas 2D와 Web Audio로 실행하며 외부 CDN이나 런타임 패키지가 없다.

## 실행

Node.js 24:

```sh
cd seventh-bell
npm run dev                 # http://localhost:4190/
npm test
npm run test:browser
npm run test:interaction
npm run test:chapters
npm run test:archive         # 앞의 세 장을 실제로 완주한 저장에서 이어서 검사
npm run test:workshops       # 획득한 돈으로 지역 정비·이동·부적을 검사
npm run build
```

브라우저 검사는 상위 저장소의 Playwright와 `/usr/bin/chromium`을 사용한다. `BASE_URL`로 배포용 정적 서버도 검사한다. 빌드한 `dist/`를 HTTP 정적 호스팅에 제공하면 된다. HTML과 상대 모듈 import, 이미지 요청에 같은 배포 식별자를 붙여 이전 버전의 모듈이 섞이는 것을 막는다.

## 네 지역

| 장 | 실제 경로와 장치 | 보스와 보상 |
| --- | --- | --- |
| 1 · 잊힌 성벽 | 성벽, 순례교, 지하 묘지, 성문 레버, 승강기, 엘마의 납 부탁 | 에드란, 두 번째 도약·잔향 감지, 대성당 문 |
| 2 · 침묵의 대성당 | 신도석, 올라갈 수 있는 성가대석, 종줄 장치, 찢어진 악보, 제단 앞 체크포인트 | 마리에, 목소리 발판, 제철도시 문 |
| 3 · 불 꺼진 제철도시 | 작업장, 아래 화로실과 밸브, 출근 장부, 양쪽으로 오갈 수 있는 계단, 모루 앞 체크포인트 | 브라그, 철문을 깨는 강공격·피해 +12, 서고 문 |
| 4 · 뒤집힌 서고 | 아래 색인 장치, 실제로 펼쳐지는 책 다리, 위층 연료 장부, 정정 기록, 기록실과 누나의 입탑 기록 | 레오넬, 기억의 발판, 서고의 숨은 보물 |

15,400 세계 단위의 연속 월드다. 실제 충돌 지형과 보이는 발판은 같은 좌표를 쓴다. 보스가 지키는 문은 해당 보스의 결말을 얻어야 열린다. 동전으로 건너뛰지 않는다. 각 지역에서 기록을 찾았다면 2단계에서 약해진 수호자의 종을 안정시킬 수 있다. 그대로 공격해 쓰러뜨리는 선택도 남긴다. 네 보스의 결과와 보상은 각각 한 번만 저장된다.

마리에의 힘으로 성가대석의 숨은 보물을, 브라그의 힘으로 제철소 다락의 철문과 봉인된 도가니를 다시 살펴볼 수 있다. 순례교 위의 첫 숨은 길도 남아 있다. 레오넬의 힘을 얻으면 V로 색인 다리 위의 기억의 발판을 드러내 서고의 숨은 함에 닿는다.

서고의 입구는 브라그의 결말이 있어야 열린다. 색인 장치를 돌리고 연료 장부를 읽어야 기록실 문이 열린다. 레오넬 뒤의 입탑 기록을 읽은 다음 왕궁 문에서 이번 버전의 끝을 확인할 수 있다. **제5장 왕궁 문은 항상 잠겨 있으며 실제 플레이 범위는 정확히 제4장까지다.**

## 전투

이동에는 가속·감속, 가변 도약, 0.13초 입력 버퍼와 0.11초 코요테 타임을 쓴다. 세 번 이어치기·강공격·무적 회피·정면 막기와 패링·공명 기술이 있다. 공격 활성 시간과 스프라이트 자세를 연결하고, 한 공격은 같은 적을 한 번만 때린다.

보스의 공격 데이터는 `src/bosses.js`에 있다. 공격마다 준비·공격·회복을 분리하고, 준비를 시작한 뒤 방향과 바닥 주문의 위치를 따라 바꾸지 않는다. 공격명·대응 문구·카운트다운·반격 안내는 게임에 표시하지 않는다. 동작, 무기와 주문의 빛, 실제 소리로 관찰한다. 바닥 주문에는 세계 안에 나타나는 작은 문양만 남긴다. 일반 공격 범위선과 투사체 궤적 안내도 없앴다. 단계 전환에 남아 있던 투사체는 지우고, 화면 밖에서 공격을 시작하지 않도록 했다.

## 지역 정비와 동전

8개 체크포인트 근처에 실제 정비대가 있다. 가까이서 W 또는 상호작용 버튼을 누르면 연다. 엘마의 작업대도 같은 서비스를 제공한다. 어느 정비대에서 구입하든 같은 장비에 적용하고 저장한다.

| 용도 | 실제 효과와 비용 |
| --- | --- |
| 종강검 연마 | 단계마다 공격력 +4. 최대 +6. 35/75/115/155/195/235 동전. +3 이후는 진행한 종의 파편에 따라 한 단계씩 열린다. |
| 방어구 보강 | 단계마다 받는 피해 2 감소, 최대 +3. 90/150/230 동전. 현재 체력은 채우지 않는다. |
| 손잡이 감기 | 단계마다 공격 집중 소모 8% 감소, 정수 반올림. 최대 +2. 75/125 동전. |
| 매듭 부적 | 35 동전. 한 개만 보유한다. 다음 사망의 동전 손실을 50%에서 20%로 줄이고 소모된다. |
| 종길 이동 | 12 동전. 기록한 종으로만 이동한다. 체력·집중·포션·기술 재사용 시간과 적의 진행 상태를 초기화하지 않는다. 보스전/근처 적/미발견 종/현재 종은 이동 불가다. |

돈이 모자라거나 한도가 잠겨 있거나 이미 부적을 지닌 경우에는 차감하지 않는다. 포션을 사서 반복 회복하는 기능은 추가하지 않았다.

## 지형과 문

문은 실제로 닫힌 충돌체가 있을 때만 그린다. 별도의 가느다란 철창 스프라이트를 충돌 범위에 맞추며, 열린 문을 공중에 반투명하게 남기지 않는다. 각 문의 발은 실제 바닥 위에 있고, 떠 있는 발판과 겹치지 않는지 검사한다. 길에 세워 두었던 장식용 아치·종탑은 걷는 공간에서 제거했다. 지역 안내는 작은 수레나 독서대로 바꿨다.

제철소 위 발판의 철문은 제거했다. 그 길은 자유롭게 지나가고, 세 번째 파편을 얻은 뒤 보물함 바로 앞에서 강공격으로 쇠사슬을 풀면 된다. 승강기 틀은 아래 바닥에 고정하고 실제 발판만 충돌 위치와 함께 움직인다.

일반 적도 강화했다. 기본 파수병 체력 88/공격 27, 마녀 72/24, 새 56/23이며 뒷지역에는 단계 보정을 준다. 마녀 탄은 직진하고 최대 300거리에서 소멸하며 마지막 55거리에서 흐려진다. 벽에도 막힌다. 새는 적을 발견하면 지상 근접 공격이 닿는 높이로 내려오고, 돌진 예고 중에는 높이·방향을 고정한다. 보스전 중에는 바깥 일반 적을 멈춰 협공을 방지한다.

## 회복과 저장

- 시작과 사망 후 재도전 때 **포션 3개**를 지급한다.
- 한 개로 **현재 최대 체력의 40%**를 회복한다. 0.8초 마시기 중 약 0.5초에 적용된다. 멈춰서 마셔야 하며 적용 전에 피격되면 포션만 잃는다.
- 종은 체크포인트만 기록한다. 체력·포션을 보충하지 않는다. 레벨업·능력 학습·보물·퀘스트 보상도 현재 체력을 채우지 않는다.
- 현재 체력과 남은 포션을 저장한다. 재접속으로 사용한 포션을 되돌릴 수 없다. 사망은 체크포인트 재도전과 적 초기화를 함께 기록한다.

저장 키 `seventh-bell.save.v1`은 유지하고 스키마 5로 이전한다. 0.1~0.4의 성장·동전·보물·부탁·보스 결말·체력과 남은 포션은 보존한다. 0.3에서 브라그를 완료했다면 3장 오른쪽 길로 바로 서고에 들어간다. 기존 진행에 새 장치나 보스 보상을 부여하지 않는다. 방어구·손잡이·부적은 기본 상태로 시작하고 기존 연마·동전·체력·포션은 유지한다. 이전에 열었던 도가니 함은 다시 봉인하지 않는다. 다른 게임의 저장에는 접근하지 않는다.

브라우저 전체를 게임으로 채우며 내부 카메라 해상도를 화면에 맞춘다. 1440×960에서는 720×480을 2배로 출력한다. 보간은 끈다. 터치 이동·도약·공격·회피·방어·공명과 포션 버튼도 제공한다. 세로 휴대폰에서는 조작 공간이 좁으므로 가로 화면이 편하다.

엘마에게 다가가면 게임을 멈추지 않는 말풍선이 나온다. NPC만 말하고 마지막 말 뒤에 부탁 수락/납품 선택이 나온다. 멀어지면 사라진다. 수락 후 실제 납을 가져오면 동전 20개를 한 번 받는다. 가까이서 W로 여는 칼 수리는 별도 서비스다.

## 아트와 소리

원본 PNG 15장을 실제 게임에 사용한다. 수리공 64프레임, 일반 적 48프레임, 서로 다른 보스 네 명 각 24프레임, 성벽·대성당·제철도시·서고의 별도 배경, 건축물과 지형 시트다. 서고의 책장·독서대·색인 장치·램프·상자·바닥은 전용 아틀라스를 쓴다. 투명 여백을 정리한 바닥의 윗면을 충돌 표면과 맞춘다. 정비대·수레·좁은 철창·봉인된 함과 정비 아이콘도 전용 시트를 쓴다. 캐릭터나 적을 도형으로 대신 그리지 않는다. 투사체·위험 표시·빛·안개·타격 효과에는 별도 도형 효과를 쓴다.

작품용으로 생성한 스프라이트를 그리드에서 추출해 게임 해상도로 맞추고 알파 가장자리를 정리한다. 사진이나 기존 게임 에셋을 가져오지 않았다. 출처는 [assets/LICENSE.md](assets/LICENSE.md)에 있다. 생성형 아트이며 사람이 모든 픽셀을 찍고 중간 동작을 직접 다듬은 상용 애니메이션이라고 주장하지 않는다. 일부 중간 프레임과 관절 연결은 더 다듬을 여지가 있다.

사운드는 `audio.js`의 오리지널 Web Audio 편곡과 효과다. 성우나 정식 녹음 OST는 없다.

## 검증 범위와 한계

`npm test`의 49개 검사는 이동·충돌·공격·패링·회피·포션·저장 이전·일회 보상 외에 네 보스의 예고/판정/방향 고정/연속타 간격, 투사체 사거리, 새와의 지상 전투, 지역 해금도 다룬다.

`test:browser`는 실제 키보드의 이동·점프·연속타·패링, 첫 보스 두 결말, 재방문 능력·터치·저장을 검사한다. `test:interaction`은 네 화면 크기의 전체 화면, 발끝 픽셀, 근접 말풍선, 실제 납 부탁과 제한 회복을 검사한다. `test:chapters`는 처음부터 세 지역을 이동해 장치와 기록을 얻고 실제 세 보스 AI를 상대한다. 이동과 보상·전투에서는 좌표·체력·아이템·재화를 부여하지 않는 입력 드라이버를 쓴다. 지형 연결을 분리해서 확인하기 위해 이 경로 검사에서는 일반 적만 제외한다. 일반 적과 세부 전투는 별도 검사한다. `test:archive`는 앞의 세 장 검사를 먼저 실행하고 그때 획득한 실제 체력·포션·레벨·재화를 가진 저장을 0.3 형식으로 이전해 서고를 이어 간다. 실제 이동·색인 장치·책 다리·필수 장부·선택 기록·레오넬 두 단계 전투·입탑 기록·4장 종료·새 능력으로 돌아가는 길·보상 및 재접속을 검사한다. `test:workshops`는 앞의 세 장에서 얻은 동전으로 서로 먼 정비대 두 곳의 구매·공유 상태, 유료 이동, 실제 낙사에 따른 부적 소모, 저장과 모바일 구매를 검사한다. 별도 화면 검사로 네 보스에게 공격 설명이 표시되지 않는지, 철창 그림과 충돌 범위가 같은지, 열린 문이 남지 않는지 확인한다. 스크린샷은 무시되는 `test-results/`에 남긴다.

왕궁·나머지 종과 최종 엔딩, 여러 직업과 무기/방어구는 아직 없다. 네 번째 장 끝에서 현재 범위를 명시하며, 이전 지역을 다시 탐험할 수 있다. 모든 적이 있는 상태에서의 장시간 수동 완주나 다양한 실제 휴대폰의 성능을 검증했다고 주장하지 않는다.
