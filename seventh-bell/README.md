# 잔향: 일곱 번째 종

**ECHOES OF THE SEVENTH BELL · 0.3.0**

이름 없는 종 수리공이 누나의 편지를 들고 왕국으로 돌아온다. 잊힌 성벽, 침묵의 대성당, 불 꺼진 제철도시가 하나의 횡스크롤 월드로 이어진다. 에드란·마리에·브라그를 만나고 세 종의 파편을 얻는 **제1~3장**을 플레이할 수 있다.

이 폴더는 독립된 게임이다. VOIDRUN과 ELDERMERE의 코드·에셋·저장을 사용하지 않는다. Canvas 2D와 Web Audio로 실행하며 외부 CDN이나 런타임 패키지가 없다.

## 실행

Node.js 24:

```sh
cd seventh-bell
npm run dev                 # http://localhost:4190/
npm test
npm run test:browser
npm run test:interaction
npm run test:chapters
npm run build
```

브라우저 검사는 상위 저장소의 Playwright와 `/usr/bin/chromium`을 사용한다. `BASE_URL`로 배포용 정적 서버도 검사한다. 빌드한 `dist/`를 HTTP 정적 호스팅에 제공하면 된다. HTML과 상대 모듈 import, 이미지 요청에 같은 배포 식별자를 붙여 이전 버전의 모듈이 섞이는 것을 막는다.

## 세 지역

| 장 | 실제 경로와 장치 | 보스와 보상 |
| --- | --- | --- |
| 1 · 잊힌 성벽 | 성벽, 순례교, 지하 묘지, 성문 레버, 승강기, 엘마의 납 부탁 | 에드란, 두 번째 도약·잔향 감지, 대성당 문 |
| 2 · 침묵의 대성당 | 신도석, 올라갈 수 있는 성가대석, 종줄 장치, 찢어진 악보, 제단 앞 체크포인트 | 마리에, 목소리 발판, 제철도시 문 |
| 3 · 불 꺼진 제철도시 | 작업장, 아래 화로실과 밸브, 출근 장부, 양쪽으로 오갈 수 있는 계단, 모루 앞 체크포인트 | 브라그, 철문을 깨는 강공격·피해 +12, 서고 쪽 기록 |

11,220 세계 단위의 연속 월드다. 실제 충돌 지형과 보이는 발판은 같은 좌표를 쓴다. 보스가 지키는 문은 해당 보스의 결말을 얻어야 열린다. 동전으로 건너뛰지 않는다. 각 지역에서 기록을 찾았다면 2단계에서 약해진 수호자의 종을 안정시킬 수 있다. 그대로 공격해 쓰러뜨리는 선택도 남긴다. 세 보스의 결과와 보상은 각각 한 번만 저장된다.

마리에의 힘으로 성가대석의 숨은 보물을, 브라그의 힘으로 제철소 다락의 철문과 봉인된 도가니를 다시 살펴볼 수 있다. 순례교 위의 첫 숨은 길도 남아 있다.

## 전투와 예고

이동에는 가속·감속, 가변 도약, 0.13초 입력 버퍼와 0.11초 코요테 타임을 쓴다. 세 번 이어치기·강공격·무적 회피·정면 막기와 패링·공명 기술이 있다. 공격 활성 시간과 스프라이트 자세를 연결하고, 한 공격은 같은 적을 한 번만 때린다.

보스의 공격 데이터는 `src/bosses.js`에 있다. 공격마다 준비 자세, 이름, 대응 안내, 진행 표시, 실제 판정과 연결된 바닥 표시를 제공한다. 준비는 0.95~1.6초다. 방향과 바닥 공격 위치는 준비를 시작할 때 정하며 뒤늦게 플레이어를 따라 돌리지 않는다. 기본 회복 동작은 1.15~1.65초다. 두 번 휘두르기는 첫 타 뒤 0.5초 틈과 새 0.85초 예고를 둔다. 단계 전환은 공격/회복 뒤에 시작하고 남아 있는 투사체를 지운다. 180거리 안에 들어오기 전에는 공격을 시작하지 않으며, 전투 카메라는 두 인물을 함께 보여 주도록 움직인다.

| 보스 | 구별되는 패턴 |
| --- | --- |
| 에드란 | 허리에서 횡베기, 머리 위 종 내려찍기와 낮은 파동, 몸을 낮춘 돌진, 2단계 두 번 베기 |
| 마리에 | 지팡이 찌르기, 직진하는 목소리, 바닥 종소리, 위치가 먼저 표시되는 기도 |
| 브라그 | 머리 위 망치와 파동, 허리에서 휘두르기, 틈이 남는 화로 분출, 돌진과 되돌아오는 망치 |

일반 적도 강화했다. 기본 파수병 체력 88/공격 27, 마녀 72/24, 새 56/23이며 뒷지역에는 단계 보정을 준다. 마녀 탄은 직진하고 최대 300거리에서 소멸하며 마지막 55거리에서 흐려진다. 벽에도 막힌다. 새는 적을 발견하면 지상 근접 공격이 닿는 높이로 내려오고, 돌진 예고 중에는 높이·방향을 고정한다. 보스전 중에는 바깥 일반 적을 멈춰 협공을 방지한다.

## 회복과 저장

- 시작과 사망 후 재도전 때 **포션 3개**를 지급한다.
- 한 개로 **현재 최대 체력의 40%**를 회복한다. 0.8초 마시기 중 약 0.5초에 적용된다. 멈춰서 마셔야 하며 적용 전에 피격되면 포션만 잃는다.
- 종은 체크포인트만 기록한다. 체력·포션을 보충하지 않는다. 레벨업·능력 학습·보물·퀘스트 보상도 현재 체력을 채우지 않는다.
- 현재 체력과 남은 포션을 저장한다. 재접속으로 사용한 포션을 되돌릴 수 없다. 사망은 체크포인트 재도전과 적 초기화를 함께 기록한다.

저장 키 `seventh-bell.save.v1`은 유지하고 스키마 3으로 이전한다. 0.1/0.2의 성장·동전·보물·부탁·첫 보스의 결말과 남은 포션은 보존한다. 새 두 장은 잠긴 상태에서 시작한다. 다른 게임의 저장에는 접근하지 않는다.

## 조작과 화면

| 입력 | 동작 |
| --- | --- |
| A D / ← → | 이동 |
| Space | 도약 · 첫 파편 이후 두 번째 도약 |
| Shift | 회피 · 길게 누르면 달리기 |
| J / Z / 좌클릭 | 일반 공격 · 세 번 이어치기 |
| K / X | 강공격 · 세 번째 파편 이후 철문 파괴 |
| L / C / 우클릭 | 막기 · 맞기 직전에 패링 |
| Q / H / V | 공명 기술 / 포션 / 잔향 감지 |
| W / E / ↑ | 장치·기록·상자·칼 수리 |
| I / Tab / M / Esc | 수첩 / 수첩 / 지도 / 메뉴 |

브라우저 전체를 게임으로 채우며 내부 카메라 해상도를 화면에 맞춘다. 1440×960에서는 720×480을 2배로 출력한다. 보간은 끈다. 터치 이동·도약·공격·회피·방어·공명과 포션 버튼도 제공한다. 세로 휴대폰에서는 조작 공간이 좁으므로 가로 화면이 편하다.

엘마에게 다가가면 게임을 멈추지 않는 말풍선이 나온다. NPC만 말하고 마지막 말 뒤에 부탁 수락/납품 선택이 나온다. 멀어지면 사라진다. 수락 후 실제 납을 가져오면 동전 20개를 한 번 받는다. 가까이서 W로 여는 칼 수리는 별도 서비스다.

## 아트와 소리

원본 PNG 11장을 실제 게임에 사용한다. 수리공 64프레임, 일반 적 48프레임, 서로 다른 보스 세 명 각 24프레임, 성벽·대성당·제철도시의 별도 배경, 건축물과 지형 시트다. 캐릭터나 적을 도형으로 대신 그리지 않는다. 투사체·위험 표시·빛·안개·타격 효과에는 별도 도형 효과를 쓴다.

작품용으로 생성한 스프라이트를 그리드에서 추출해 게임 해상도로 맞추고 알파 가장자리를 정리한다. 사진이나 기존 게임 에셋을 가져오지 않았다. 출처는 [assets/LICENSE.md](assets/LICENSE.md)에 있다. 생성형 아트이며 사람이 모든 픽셀을 찍고 중간 동작을 직접 다듬은 상용 애니메이션이라고 주장하지 않는다. 일부 중간 프레임과 관절 연결은 더 다듬을 여지가 있다.

사운드는 `audio.js`의 오리지널 Web Audio 편곡과 효과다. 성우나 정식 녹음 OST는 없다.

## 검증 범위와 한계

단위 검사는 이동·충돌·공격·패링·회피·포션·저장 이전·일회 보상 외에 세 보스의 예고/판정/방향 고정/연속타 간격, 투사체 사거리, 새와의 지상 전투, 지역 해금도 다룬다.

`test:browser`는 실제 키보드의 이동·점프·연속타·패링, 첫 보스 두 결말, 재방문 능력·터치·저장을 검사한다. `test:interaction`은 네 화면 크기의 전체 화면, 발끝 픽셀, 근접 말풍선, 실제 납 부탁과 제한 회복을 검사한다. `test:chapters`는 처음부터 세 지역을 이동해 장치와 기록을 얻고 실제 세 보스 AI를 상대한다. 이동과 보상·전투에서는 좌표·체력·아이템·재화를 부여하지 않는 입력 드라이버를 쓴다. 지형 연결을 분리해서 확인하기 위해 이 경로 검사에서는 일반 적만 제외한다. 일반 적과 세부 전투는 별도 검사한다. 스크린샷은 무시되는 `test-results/`에 남긴다.

뒤집힌 서고·왕궁·나머지 종과 최종 엔딩, 여러 직업과 무기/방어구는 아직 없다. 세 번째 장 끝에서 현재 범위를 명시하며, 이전 지역을 다시 탐험할 수 있다. 모든 적이 있는 상태에서의 장시간 수동 완주나 다양한 실제 휴대폰의 성능을 검증했다고 주장하지 않는다.
