# 잔향: 일곱 번째 종

**ECHOES OF THE SEVENTH BELL · 0.2.0**

이름 없는 종 수리공이 누나의 편지를 들고 잊힌 성벽에 돌아온다. 성문 아래의 묘지를 지나 에드란을 만나고, 첫 파편을 얻어 지나온 길의 다른 층을 탐험하는 횡스크롤 액션 RPG다.

화면은 브라우저 전체를 게임으로 채운다. 화면 비율에 맞춰 실제 카메라와 내부 해상도를 바꾸며 캐릭터를 늘려 그리지 않는다. 바깥 제목 표시줄과 하단 설명은 없애고 메뉴·체력·기록 버튼을 월드 위에 작게 뒀다.

엘마에게 다가가면 게임을 멈추지 않는 말풍선이 나온다. 엘마만 말하며, 끝까지 들으면 부탁의 수락/나중에 선택이 나온다. 멀어지면 사라진다. 수락한 뒤 발판을 타고 보급함에서 납을 찾고 돌아오면 동전 20개를 한 번 받는다. 칼 수리는 가까이서 W로 별도 작업대를 연다.

이 폴더만으로 실행·빌드할 수 있다. VOIDRUN과 ELDERMERE의 소스·에셋·진입점·저장을 사용하지 않는다. 별도 런타임 패키지나 외부 CDN 없이 Canvas 2D와 Web Audio로 실행한다.

## 실행

Node.js 24 기준:

```sh
cd seventh-bell
npm run dev
# http://localhost:4190/
npm test
npm run test:browser
npm run build
```

브라우저 검사는 상위 저장소에 설치된 Playwright와 `/usr/bin/chromium`을 사용한다. `BASE_URL`로 정적 빌드나 다른 서버를 검사할 수 있다. 빌드 결과 `dist/`를 정적 호스팅에 올리면 된다. ES 모듈 때문에 HTML을 파일 탐색기에서 직접 열지 말고 HTTP로 제공해야 한다.

## 이번 버전에서 할 수 있는 일

- 4,540 세계 단위의 연속 구역: 성벽 밖, 끊어진 순례교, 하층 묘지, 회랑, 에드란의 초소. 위치에 따라 높이와 카메라가 바뀐다.
- 가속·감속, 가변 높이 점프, 0.13초 입력 버퍼, 0.11초 코요테 타임, 달리기, 무적 회피.
- 3연타, 강공격, 정면 방어와 짧은 패링, 공명 기술, 경직·넉백·타격 정지. 공격별 활성 프레임과 한 공격당 한 번의 적중 기록을 검사한다.
- 망가진 파수병, 등불을 든 창도자, 날아다니는 잔향의 세 종류. 준비·공격·회복·피격·사망 상태와 실제 시트 프레임을 사용한다.
- 전용 보스 에드란: 420 체력, 두 단계, 횡베기·종 내려찍기/충격파·돌진·두 번째 단계 연속타. 공격을 받아치면 반격 시간이 생긴다.
- 초반 돌 발판은 기본 점프만으로 차례로 오를 수 있다. 캐릭터·정적인 물체의 투명한 아래 여백을 발끝 기준에 반영하고, 지형은 렌더링과 충돌이 같은 표면 좌표를 쓴다.
- 묘지의 수첩을 찾으면 에드란이 약해졌을 때 종을 안정시킬 수 있다. 그대로 공격해 쓰러뜨릴 수도 있다. 결과는 저장되고 조명·음악·엘마의 말·추가 잔향의 등장에 반영된다.
- 레버와 성문, 실제로 플레이어를 싣고 움직이는 승강기, 두 체크포인트, 선택 보물, 죽을 때 남기는 동전과 회수.
- 보스 뒤에 두 번째 공중 도약과 잔향 감지를 얻는다. 순례교에 돌아가 임시 발판을 드러내면 처음에는 갈 수 없던 보물에 닿는다.
- 레벨·경험·능력 3개, 종강검 수리 +3, NPC 수리와 실제 아이템을 건네는 부탁, 제한된 회복 약병, 수첩과 실제 위치를 표시하는 지도.
- 저장 키 `seventh-bell.save.v1`. 동전·성장·장치·보물·보스의 결말을 저장한다. 보스전 도중 재접속하면 체크포인트에서 다시 도전한다.

## 조작

| 입력 | 동작 |
| --- | --- |
| A D / ← → | 이동 |
| Space | 도약 · 파편 획득 후 두 번째 도약 |
| Shift | 회피 · 계속 누르면 달리기 |
| J / Z / 좌클릭 | 일반 공격 · 다시 눌러 이어치기 |
| K / X | 강공격 |
| L / C / 우클릭 | 막기 · 맞기 직전 패링 |
| Q | 공명 기술 |
| H | 멈춰 서서 약병 마시기 |
| W / E / ↑ | 장치·체크포인트·칼 수리 |
| V | 잔향 감지 · 첫 보스 이후 |
| I / Tab, M, Esc | 수첩, 지도, 메뉴 |

터치 이동·도약·공격·회피·방어·공명 버튼과 약병 버튼도 있다. 전투와 화면 구성은 PC를 우선으로 다듬었으며, 작은 세로 화면은 조작 공간이 좁다.

## 회복 제한

- 약병은 최대 1개이며 한 번에 체력 30, 집중 25를 쓴다.
- 지상에서 멈춰 서서 마셔야 한다. 0.9초 동작의 약 0.65초 시점에 체력이 찬다. 도중에 맞으면 약병은 소모되고 회복하지 못한다.
- 종 앞에서는 체력이 차지 않는다. 새 체크포인트를 처음 발견할 때 약병을 최대 한 번 보충하며, 같은 종을 반복 눌러 약병을 얻을 수 없다. 처음 시작하는 종은 이미 챙긴 것으로 기록한다.
- 레벨업과 최대 체력 능력은 현재 체력을 채워 주지 않는다. 상자와 NPC 부탁 보상에도 회복을 넣지 않았다.
- 사망 후 체크포인트에서 재도전할 때는 체력과 약병 1개를 복구하고 적·보스를 초기화한다. 진행 중 종을 누르는 회복과 구분한다.

저장은 같은 키를 유지하면서 스키마 2로 이전한다. 0.1 저장의 성장·장치·보스·보물·동전을 유지하고, 약병만 새 상한 1개로 맞춘다. 이미 보급함을 연 플레이어에게는 새 부탁에 필요한 납의 보유 상태를 이어 준다. 완료한 기존 도움은 다시 보상하지 않는다.

## 아트와 소리

사진이나 기존 게임의 그래픽을 가져오지 않았다. 이 작품을 위해 생성한 캐릭터·적·보스·지형·배경의 원본 PNG를 `assets/`에 보관한다. 생성된 시트에서 프레임을 직접 추출해 사용하며, 실행 중 도형으로 캐릭터나 적을 대신 그리는 코드가 없다. 스파크·무기 궤적·안개·광원은 별도 효과다.

`art.js`는 실제 그리드와 지형 시트의 행 위치를 기록하고, 수리공/일반 적 64px, 보스/오브젝트 128px 셀에 프레임을 맞춘다. 보간을 끄고 알파 가장자리를 정리한다. 기본 픽셀 단위를 유지하면서 화면에 따라 내부 카메라 크기를 조정한다. 1440×960에서는 720×480을 2배로 출력하고, 휴대폰에서는 폭을 최소 360 세계 단위로 유지해 화면을 채운다. 사진을 도트 필터로 바꾸는 처리나 절차적 사람/몬스터 생성은 없다. 원본은 생성형 도구로 제작한 스프라이트이며 사람이 모든 픽셀과 중간 프레임을 직접 수정한 상용 에셋이라고 주장하지 않는다.

수리공 64셀, 일반 적 48셀, 에드란 24셀을 제작했다. 일부 대기 프레임의 차이는 작고, 일반 적의 피격·사망은 2프레임이다. 걷기·달리기·날갯짓은 8프레임을 쓴다. 애니메이터의 수작업으로 관절과 실루엣을 더 다듬을 여지가 있다. 출처는 [assets/LICENSE.md](assets/LICENSE.md)에 기록했다.

배경 두 장과 실제 월드의 건축물을 서로 다른 속도로 움직여 깊이를 만들고, 광원·안개·재를 덧그린다. 소리는 외부 음원을 사용하지 않는 짧은 오리지널 Web Audio 편곡과 효과다. 정식 녹음 음원·성우·완성된 장편 OST는 없다.

## 검증 범위

`npm test`의 21개 검사는 기존 저장 이전, 제한된 회복과 중단, 종·성장·보상의 회복 우회 방지, 근접 말풍선과 실제 부탁 보상도 다룬다. 기본 검사는 이동·충돌, 점프 버퍼/코요테, 연속 공격과 실제 활성 시간, 공격 방향·벽, 패링·방어·회피, 스킬 비용과 재사용, 승강기, 보스 두 단계/두 결말, 거래·성장·일회 보상, 새 이동 능력, 죽음·동전 회수·저장을 검사한다.

`test:browser`는 실제 키보드로 이동·점프·3연타·패링을 검사한다. 구역 연결 검사에서는 적을 제거해 지형만 분리하고, 좌표를 부여하지 않는 입력 드라이버로 다리·묘지·레버·승강기·보스 입구까지 이동한다. 보스 검사는 실제 AI·공격·패링·회복과 자원 비용을 사용하며, 보상 함수를 직접 호출하지 않는다. 보스 이후 재방문 검사에서도 적을 제외해 지형을 분리하고, 실제 입력과 물리로 묘지를 되짚어 가서 새 발판과 보물을 확인한다. 터치 검사와 저장 복원도 포함한다. `npm run test:interaction`은 네 화면 크기의 전체 화면 출력, 실제 발끝의 픽셀 기준, 근접 말풍선의 시작/완료/이탈, 기본 점프로 오르는 발판 경로, 납 획득·납품·수리, 지연 회복 한 번과 저장 복원을 별도로 검사한다. 스크린샷은 무시되는 `test-results/`에 저장한다.

## 아직 없는 것

완성한 범위는 **제1장과 보스 한 명**이다. 대성당·제철도시·서고·왕궁, 나머지 종과 보스, 세 가지 최종 엔딩은 이번 버전에 구현하지 않았다. 기존 세계관을 잇는 설계는 [STORY.md](STORY.md)에 남겼다. 여러 직업·무기/방어구·대규모 스킬 트리도 아직 없다. 현재의 한 무기와 세 능력을 넓힐 수 있도록 판정 데이터, 저장, 아트, 월드, UI를 나눴다.

일곱 종 전체를 완성했다거나 정식 출시 수준의 콘텐츠와 모든 애니메이션이 준비됐다고 부르지 않는다. 이번 결과는 실제 플레이와 아트를 연결한 첫 장이다.

빌드 시 HTML과 모든 모듈의 상대 import, 아트 요청에 같은 배포 식별자를 붙인다. 새 HTML에 예전 카메라·저장 모듈이 섞이지 않게 하기 위한 캐시 처리이며, 별도 런타임 의존성은 없다.
